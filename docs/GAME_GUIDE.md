## 2. 세계관과 이야기

- **무대**: 전지의 힘으로 불을 밝히는 "반짝마을". 오늘 밤은 일 년에 한 번 열리는 불빛 축제 날입니다. 그런데 해가 지자 마을이 어두워졌습니다.
- **주인공**: 학생(또는 학생 모둠) = "탐험대". 이야기 속 인물이 학생이 정한 이름(혼자 하기) 또는 모둠 이름(모둠으로 하기)으로 부릅니다.
- **안내 인물**: 마을의 불빛을 지키는 빛 요정 "반디"(꼬리가 빛나는 반딧불이). 탐험대에게 도움을 요청하고 각 단계를 안내합니다.
- **마을 사람**: 여러 동물(병아리, 곰 등). 장소마다 문제 상황을 말풍선으로 알려 줍니다.
- **문제**: 가로등이 꺼져 있고, 광장의 안내 종이 울리지 않고, 언덕의 풍차가 멈춰 있어 축제를 열 수 없습니다.
- **해결**: 미션 세 개를 해결할 때마다 그 장소가 되살아나고 마을이 점점 밝아집니다. 세 곳을 모두 되살리면 마을 전체에 불이 켜지고 불꽃놀이와 함께 축제가 시작됩니다.
- 교과서 3차시 이야기와는 잇지 않은, 이 게임만의 이야기입니다.

## 3. 전체 흐름

```
오프닝 영상 → S1 입장 → 캐릭터 고르기 → S2 도입(이야기 5장면) → S3 마을 지도 ⇄ S4 미션(3개) → S5 마무리(5단계 + 마치기) → 축제 엔딩
```

| 단계 | 화면 | 하는 일 | POE |
|---|---|---|---|
| 0 | 오프닝 | 밤의 반짝마을이 나타나는 짧은 연출. "시작하기" 또는 "건너뛰기" | - |
| 1 | S1 입장 | 혼자 하기 / 모둠으로 하기 선택, 이름 입력, 안전 약속 체크 | - |
| 2 | S2 도입 | 반디의 이야기, 회로 조건 떠올리기, 전지 제품 이야기와 예상 | 사전 지식 확인 |
| 3 | S3 지도 | 마을을 돌아다니며 미션 장소 찾기 | - |
| 4 | S4 미션 ×3 | 예상 → 만들기 → 비교·이유 → 확인 | P → O → E |
| 5 | S5 마무리 | 결과 모으기, 확인하기(용어 "직렬연결" 처음 등장), 적용하기, 오개념 점검, 스스로 평가 | 정리·평가 |

## 4. 화면별 상세 기능

### 4-1. 오프닝
- 밤하늘, 반딧불, 어두운 마을이 차례로 나타나는 애니메이션과 제목 "불빛 탐험대 / 꺼진 마을을 밝혀라".
- 처음 접속하거나 "처음부터 다시 하기"를 했을 때만 나옵니다.

### 4-2. S1 입장
- **혼자 하기**: "내 이름을 써 주세요." 칸에 이름을 씁니다(예: 민수). 반디가 이 이름으로 부릅니다.
- **모둠으로 하기**: 선생님이 미리 만든 모둠 목록(1모둠, 2모둠 …)에서 우리 모둠을 고르고, "내 이름을 써 주세요."에 이름을 씁니다.
- **안전 약속 3가지**를 모두 체크해야 시작할 수 있습니다.
  1. 전기 부품을 만질 때는 절연 장갑을 끼고, 젖은 손으로 만지지 않아요.
  2. 전구의 유리 부분은 깨지기 쉬우니 조심해서 다뤄요.
  3. 전선의 집게에 손이 끼지 않게, 날개 달린 전동기에 손을 다치지 않게 조심해요.
- 모두 마치고 "다음 →"을 누르면 **캐릭터 고르기 화면**으로 넘어갑니다.

### 4-2-1. 캐릭터 고르기 (게임 아바타 고르기)
- 밤하늘 무대 가운데 조명 위에 탐험대 캐릭터 한 마리를 크게 보여 줍니다. 제목 "함께 탐험할 내 캐릭터를 골라요".
- 양옆 꺾쇠(‹ ›), 키보드 ←/→, 아래 점으로 하나씩 넘겨 봅니다. 넘기는 방향대로 캐릭터가 스르륵 들어옵니다.
- 캐릭터 6가지, 모두 탐험대 표시인 노란 머리 전등 헬멧과 민트색 목도리를 씁니다. 캐릭터마다 다른 귀여운 움직임을 하고, 숨 쉬듯 살짝 움직입니다.

| 캐릭터 | 소개 | 움직임 |
|---|---|---|
| 강아지 (기본) | 냄새로 길을 잘 찾아요 | 통통 튀며 좌우로 |
| 토끼 | 귀가 밝아서 작은 소리도 잘 들어요 | 깡충 |
| 고양이 | 어두운 곳도 잘 봐요 | 살랑살랑 |
| 곰 | 힘이 세고 듬직해요 | 둥실둥실 |
| 병아리 | 부지런하고 씩씩해요 | 파닥 점프 |
| 공룡 | 큰 발로 쿵쿵 씩씩하게 걸어요 | 쿵쿵 발 구르기 |

- "이 캐릭터로 출발!"(또는 Enter)을 누르면 시작하고, "‹ 뒤로"로 입장 화면에 돌아가 고칠 수 있습니다(쓴 이름은 남아 있음).
- 고른 캐릭터가 나오는 곳: 도입 마지막 장면("마을로 출발" 장면)의 탐험대, 지도에서 내가 움직이는 캐릭터. 모둠으로 할 때는 친구 화면에서도 내가 고른 모습으로, 친구 캐릭터는 친구가 고른 모습으로 보입니다.
- 캐릭터 고르기 화면은 열 때마다 첫 번째(강아지)부터 보여 줍니다. 고른 캐릭터는 기기에 저장되어 새로고침해도 유지됩니다.
- 캐릭터 소개 문장은 게임 내용과 이어지게 골랐습니다(예: 고양이 "어두운 곳도 잘 봐요" → 어두운 마을, 토끼 "작은 소리도 잘 들어요" → 안내 종).
- 움직임 줄이기 설정을 켠 기기에서는 캐릭터 움직임과 넘김 효과를 멈춥니다.
- **설계 의도**: 학생이 자기를 나타내는 캐릭터를 직접 고르게 해 몰입과 소속감을 높이고, 모둠 활동에서 지도·화면 위 친구를 캐릭터로 쉽게 알아보게 합니다. 모든 캐릭터에 같은 헬멧과 목도리를 씌워 "탐험대"임을 드러내고 마을 동물과 구별합니다.

### 4-3. S2 도입 (이야기 5장면)
화면 양옆의 꺾쇠(‹ ›)나 키보드 ←/→로 넘깁니다. 장면마다 움직이는 그림이 있고, 그 아래 반디의 대사가 **연한 보라색 말풍선**(반디 쪽으로 뾰족한 꼬리, 그림자 없음)으로 나옵니다. 질문이 있는 장면은 말풍선 아래 흰 상자에서 답을 고릅니다.

| 장면 | 내용 |
|---|---|
| 1 | 해설: 반짝마을, 불빛 축제 날인데 마을이 어둡다 |
| 2 | 반디 등장: "○○, 와 줘서 고마워요! … 가로등은 꺼져 있고, 광장의 안내 종은 울리지 않고, 언덕의 풍차는 멈춰 있어요." |
| 3 | **회로 조건 떠올리기**(복습): "전구에 불이 켜지려면 전지의 양 끝과 전구, 전선이 ( ) 연결되어 있어야 해요." → 끊기지 않게 / 끊기게. 고르면 빈칸이 채워지고 맞음·틀림 안내가 나옵니다 |
| 4 | **전지 제품 이야기**(손 선풍기·손전등·리모컨): ① "전기 제품마다 넣는 전지의 개수가 다른 까닭은 무엇일까요?"(필요한 전기의 양이 달라서 / 많을수록 무조건 좋아서 / 잘 모르겠어요) ② "손 선풍기에 전지를 1개 넣을 때와 2개 넣을 때, 어느 쪽 바람이 더 셀까요?"(전지 1개를 넣을 때 / 전지 2개를 넣을 때 / 바람의 세기가 같아요) |
| 5 | 반디의 부탁: "전지의 개수를 달리해서 축제 전에 반짝마을을 다시 밝혀 줄래요?" → "마을로 출발" |

### 4-4. S3 반짝마을 지도 (돌아다니기)

**움직이기**
- 입장 때 고른 탐험대 캐릭터(머리 전등 헬멧과 목도리를 쓴 동물, 곁에 반디가 따라 날아다님)를 **직접 움직여** 마을을 돌아다닙니다. 걸을 때는 한 발씩 번갈아 디디며 몸이 디딘 발 쪽으로 기울고, 가는 방향을 바라봅니다. 발밑의 노란 빛 고리로 내 캐릭터를 구별합니다.
- 조작 세 가지(모두 함께 쓸 수 있음)
  1. 키보드 방향키 또는 W·A·S·D
  2. 가고 싶은 곳을 마우스·손가락으로 누르기 → 그곳까지 알아서 걸어감
  3. 화면 오른쪽 아래 **조이스틱**(동그라미를 끌기, 태블릿용)
- 장소 안에 서서 Enter·Space를 누르거나 장소를 한 번 더 누르면 그 장소 창이 열립니다.
- 길과 상관없이 늘 다음 미션 장소를 곧장 가리키는 **나침반 화살표**가 캐릭터 둘레에 있고, 장소 위에는 아래로 내려 꽂히는 반짝이는 화살표가 있습니다.

**보기 두 가지** (오른쪽 위 "탐험 / 지도", 흰 칸이 옆으로 미끄러지며 바뀜)
- **탐험**(기본): 캐릭터를 따라가며 5배로 크게 봅니다. 돌길, 풀, 꽃, 연못, 길가 등, 장소마다 문제를 말하는 마을 동물(말풍선)이 자세히 보입니다. 걷는 빠르기는 느려져 장소 사이가 멀게 느껴집니다.
- **지도**: 마을 전체를 한눈에 보는 단순한 그림. 빨리 이동할 때 씁니다.

**위쪽 줄**: 왼쪽 "나가기", 가운데 "[이름] 미션 n/3 완료"와 별 세 개(완료한 미션만큼 노랗게 채워짐), 오른쪽 "탐험/지도" 전환과 소리 버튼. 모두 반투명 알약 모양이라 지도를 가리지 않습니다.

**처음 도착했을 때**
1. 반디의 인사(화면 왼쪽 아래 반디와 말풍선): "○○, 반짝마을에 온 것을 환영해요! 가로등부터 시작해 볼까요? 반짝이는 화살표를 따라가 보세요." → "알겠어요!"
2. **움직이는 방법 튜토리얼** 4단계 카드(캐릭터 아래에 뜸): ① 방향키로 걸어요 ② 조이스틱으로 걸어요 ③ 눌러서 가요(지도의 한 곳을 누르는 커서 그림) ④ 화살표를 따라가요. 튜토리얼 중에는 **연습 모드**라 돌아다닐 수만 있고 미션 장소에 닿아도 열리지 않으며, 끝나면 처음 자리로 돌아와 진짜로 출발합니다.
3. 왼쪽 아래 "?"를 누르면 "방향키나 조이스틱으로 움직이거나, 가고 싶은 곳을 눌러요." 안내와 "튜토리얼 다시 보기"가 나옵니다.

**미션 장소 3곳** (앞 미션을 해결해야 다음 장소가 열림. 잠긴 곳은 자물쇠, 완료한 곳은 별 표시)

| 장소 | 미션 | 문제 상황 | 우리가 할 일 | 마을 동물의 말 (전 → 후) |
|---|---|---|---|---|
| 가로등 거리 | 미션 1 | 가로등이 모두 꺼져서 밤길이 깜깜해요. 축제에 오는 사람들이 길을 잃고 있어요. | 전지의 개수를 달리하면 전구의 밝기가 어떻게 달라지는지 알아보고, 가로등을 다시 밝혀요. | "앞이 안 보여요" → "이제 환해요!" |
| 광장의 안내 종 | 미션 2 | 안내 종을 쳐도 소리가 들리지 않아요. 축제가 시작된다는 것을 아무도 알 수 없어요. | 전지의 개수를 달리하면 버저 소리가 어떻게 달라지는지 알아보고, 종소리를 되살려요. | "소리가 안 들려요" → "종소리가 울려요!" |
| 언덕의 풍차 | 미션 3 | 풍차가 멈춰 있어요. 풍차가 돌아야 축제 무대에 불을 켤 힘이 모여요. | 전지의 개수를 달리하면 전동기가 도는 빠르기가 어떻게 달라지는지 알아보고, 풍차를 다시 돌려요. | "꼼짝도 안 해요" → "씽씽 돌아요!" |

- 장소에 도착하면 화면 가운데에 **상황 창**이 뜹니다: 위쪽 움직이는 상황 장면(밤 풍경, 꺼진 가로등, 길 잃은 동물 등), 아래 "문제 상황"(분홍 상자)과 "우리가 할 일"(노란 상자), "미션 시작!" 버튼, 오른쪽 위 ✕. 창이 뜰 때 "띠링" 효과음이 납니다.
- 잠긴 장소에 가면 "앞의 미션을 먼저 해결해야 열려요!"가 뜹니다.
- 완료한 장소는 밝아진 장면, "이미 성공한 미션이에요.", 그리고 "다시 하기"(① 예상부터 빈 회로판으로 새로) / "결과 확인하기"(완료할 때의 회로판과 결과를 보기만) 버튼이 나옵니다.

**되살아남과 마을 밝기**
- 미션을 마치고 돌아오면 그 장소가 **되살아나는 장면**(어둡던 곳이 서서히 밝아지고, 가로등이 켜지고, 종이 울리고, 풍차가 돔)과 반디의 다음 안내가 나옵니다.
  - 미션 1 뒤: "가로등 거리가 환해졌어요! 그런데 광장의 안내 종은 아직 울리지 않아요. 광장으로 가 볼까요?"
  - 미션 2 뒤: "종소리가 마을 끝까지 울려 퍼져요! 이제 언덕 위 풍차만 남았어요. 언덕으로 올라가 볼까요?"
  - 미션 3 뒤: "풍차가 씽씽 돌고 마을 전체에 불이 켜졌어요! 불빛 축제를 열 수 있게 됐어요. 이제 오늘 알게 된 것을 정리하러 가요." → "마무리로 가기"
- 되살린 곳이 늘수록 마을 전체의 어두움이 4단계로 걷힙니다.

### 4-5. S4 미션 화면 (공통 틀)
화면 구성: 위쪽 줄(미션 제목, 단계 칩 "예상·만들기·비교·이유·확인", 나가기·지도·어둡게 보기·소리 버튼) / 왼쪽 A 회로판(전지 1개) / 가운데 B 회로판(전지 2개) / 오른쪽 학습지 / 아래 안전 문구.

**위쪽 줄**: 왼쪽 "미션 1. 가로등 밝히기" 같은 제목과 **단계 칩 4개**(예상·만들기·비교·이유·확인. 마친 단계는 연한 초록과 ✓, 지금 단계는 연한 노랑, 남은 단계는 회색). 오른쪽에 "연결 방법 다시 보기"(② 만들기에서만), "나가기", "지도", 어둡게 보기(달 아이콘, 미션 1만), 소리 버튼.

**미션 이야기**: 미션에 들어올 때마다(다시 하기 포함) 먼저 반디의 이야기 창이 뜹니다. 위쪽은 장소의 움직이는 장면, 아래는 반디와 한 글자씩 써지는 말풍선, 이전·다음, 건너뛰기, ✕. 마지막 장면의 버튼은 "예상하러 가기"입니다.

| 미션 | 반디의 이야기 |
|---|---|
| 1 | 여기가 가로등 거리예요. 와, 정말 깜깜하죠? / 축제에 가던 병아리가 길을 잃었대요. 할아버지 곰은 촛불 하나로 겨우 버티고 있어요. / 가로등 안에는 전구와 전지가 들어 있어요. |
| 2 | 광장에 도착했어요! 저기 안내 종 보이죠? / 여우가 종을 아무리 흔들어도 소리가 하나도 안 들려요. 친구들이 고개를 갸웃하고 있어요. / 종 안에는 소리를 내는 버저가 숨어 있어요. |
| 3 | 언덕 위 풍차까지 왔어요. 그런데 날개가 꼼짝도 안 해요. / 풍차가 돌아야 축제 무대에 불이 켜져요. 농부 돼지가 발을 동동 구르고 있어요. / 풍차 안에는 날개를 돌리는 전동기가 들어 있어요. |

| 단계 | 하는 일 | 규칙 |
|---|---|---|
| ① 예상 | 선택지 3개 중 하나를 고르고 "이걸로 정했어요" | 정한 예상은 바꿀 수 없음. 정답을 미리 알려 주지 않음 |
| ② 만들기 | 회로판에서 직접 A·B 회로를 만들고 스위치를 닫아 비교 | 오른쪽 "탐험 과제" 3칸이 판정 결과로 **자동 체크**됨. 3칸이 모두 체크되어야 "비교하러 가기" |
| ③ 비교·이유 | 문장의 빈칸 ○표 고르기(예: 전구의 밝기가 더 ( 어둡다 / 밝다 )) + 모둠 생각 적어 보기("왜 그랬을까요? 모둠의 생각을 적어 보세요.") | 생각을 **적기만 하면(글자 수 제한 없음)** "확인하기". 10글자 제한은 6학년에게 부담이 된다는 검토 의견으로 뺐습니다. 확인하기를 누르면 그 자리에서 채점(○표 맞음/틀림, 정답에 빨간 테두리)과 **모범 답안**이 나오고, 이후 고칠 수 없음 |
| ④ 확인 | 성공 축하(반디) → 내 예상 / 실제 결과, 예상이 맞았는지, 한 줄 정리, 장소 되살아남 | "지도로 돌아가기"를 누르면 미션 완료로 기록 |

**탐험 과제 자동 체크 규칙** (학생이 직접 체크하지 않음)
1. A 회로가 정상으로 이어지면(스위치를 닫으면 작동할 상태) 1번 체크
2. B 회로가 전지 2개를 서로 다른 극끼리 이은 정상 연결이면 2번 체크 (전지 1개만 넣은 고리는 체크 안 됨)
3. 두 회로가 모두 실제로 작동 중이면(스위치까지 닫힘) 3번 체크

체크리스트는 번호를 세로 줄로 이은 순서 목록으로, 지금 할 차례는 노랑, 마친 일은 초록 ✓과 취소선으로 보입니다. 위쪽에 "1/3"처럼 진행 수가 나옵니다. 한 번 정상 연결한 기록은 나중에 전선을 바꿔도 유지됩니다.

**관찰 문구**: 회로가 제대로 작동하면 각 회로판 아래에 "A 회로(전지 1개): 전구가 희미하게 켜졌어요." / "B 회로(전지 2개): 전구가 훨씬 환하게 켜졌어요!" 같은 문장이 나옵니다(예상 단계에서는 나오지 않음).

**④ 확인 화면 구성**: 반디의 축하 창("와! 마을 거리가 환해졌어요. 고마워요, 탐험대!" + "결과 보기") → 내 예상(맞았으면 초록 "맞혔어요!", 달랐으면 하늘색 상자 "예상과 달랐네요. 괜찮아요, 관찰한 결과가 중요해요.") / 실제 결과 / 한 줄 정리(예: "이번에는 전구로 확인했어요. 버저와 풍차에서도 같을까요?") / 미션 1은 "도전! 더 해 보기 (선택)" / 미션 3은 "더 알아보기 (심화)" / "지도로 돌아가기".

**POE 원칙**: 확인(④) 전에는 정답이나 원리를 보여 주지 않습니다. 미션 화면에서는 "직렬"이라는 용어도 쓰지 않습니다. 용어는 S5 확인하기에서 처음 나옵니다.

**할 곳만 밝히기**: ①·③·④에서는 화면을 어둡게 덮고 지금 할 곳(학습지)만 밝게 보여 줍니다. ② 만들기에서는 탐험 과제를 같이 봐야 해서 덮지 않습니다.

**어둡게 보기**(미션 1만): 회로판 배경을 어둡게 바꿔 전구 밝기 차이를 더 잘 보이게 합니다.

**도움말·심화**: 탐험 과제 아래 "도움말" 토글(예: "주변이 어두우면 밝기를 더 잘 볼 수 있어요."), 미션 3 확인 단계의 "더 알아보기 (심화)"(전동기 방향이 전기의 방향에 따라 바뀌는 원리).

**탐험 과제(체크리스트, 미션 1 예)**

2. B 회로: 전지 2개를 서로 다른 극끼리 한 줄로 이은 뒤 전구, 스위치를 연결해 보세요.
3. 두 회로의 스위치를 모두 닫고 전구의 밝기를 비교해 보세요.

### 4-7. 회로 시뮬레이터

**조작**
- 단자(동그란 금속 부분)를 누른 채 다른 단자까지 끌면 집게 달린 전선이 생깁니다. 단자 두 개를 차례로 눌러도 됩니다.
- 전선을 누르면 지워집니다.
- 전선 색은 교과서처럼 빨강·검정 두 가지예요. 전지의 + 단자에 닿은 전선은 빨강, 나머지는 검정입니다(꺼진 마을의 어두운 바탕에서는 진한 회색). 버저와 전동기에는 교과서처럼 빨간 선·검은 선이 달려 있습니다. 지도서 288쪽에 따라 **선 색의 뜻(빨강 = +, 검정 = −)은 힌트·도움말에서 미리 말해 주지 않습니다.** 다만 버저·전동기 단자 옆에는 전지처럼 +, − 글자를 표시합니다(색깔만으로 구분하지 않도록). 버저를 거꾸로 이어(고리는 맞게 이어짐) 스위치를 닫으면 그 회로판 아래에 바로 "종이 울리지 않아요."가 뜹니다(고치는 방법은 힌트에서). 버저가 울리지 않으면 힌트와 도움말도 "버저 양 끝에 연결한 전선을 서로 바꾸어 이어 보세요"(실험관찰 45쪽 도움말과 같은 말)라고 안내해, 학생이 반대로 연결해 보며 알아내게 합니다.
- 스위치를 누르면 열림/닫힘이 바뀝니다(처음에는 열림).
- 부품 위치는 고정되어 있고, 학생은 연결만 합니다.

**결과 표현**
- 전구: 밝기 2단계(전지 1개 희미함 / 전지 2개 환함). 전지 2개 쪽이 더 노랗고 빛번짐이 큼.
- 버저: 종소리 "딩~". 전지 2개 쪽이 확연히 크게 울림. A·B가 번갈아 울려 비교하기 쉬움.
- 전동기: 날개 회전 빠르기 차이, 도는 방향 표시.
- 전구가 켜질 때 효과음.

**판정 규칙**(순수 함수 `judge`, 단위 테스트 있음)
- 단자를 노드, 부품을 변으로 보는 그래프로 회로를 분석합니다. 부품을 지나는 닫힌 고리를 찾고, 고리 위 전지의 방향 합으로 작동 레벨(0·1·2)과 전기의 방향을 정합니다.
- 판정 결과(이유)마다 힌트 문구가 1:1로 대응합니다. 여기에 판정은 "작동"이지만 회로판이 바라는 밝기에 못 미치는 경우(ONE_BATTERY) 하나를 더합니다.

| 판정 이유 | 상황 | 힌트 문구 |
|---|---|---|
| NO_WIRES | 전선이 하나도 없음 | 부품의 끝(동그란 금속 단자)을 집게 달린 전선으로 이어 보세요. |
| BROKEN | 고리가 끊김 | 전지의 양 끝(+, −)과 부품이 끊기지 않게 이어져야 해요. 끊어진 곳이 없는지 살펴보세요. |
| SWITCH_OPEN | 연결은 맞고 스위치만 열림 | 스위치가 열려 있어요. 눌러서 닫아 보세요. |
| SWITCH_MISSING | 스위치를 빼고 고리를 만듦 | 스위치도 고리 안에 함께 이어 보세요. |
| SAME_POLE | 전지 2개를 같은 극끼리 이음 | 전지 2개는 서로 다른 극끼리 이어야 해요. 한 전지의 + 와 다른 전지의 − 를 이어 보세요. |
| BUZZER_REVERSED | 버저 극을 반대로 이음 | 버저가 울리지 않으면 버저 양 끝에 연결한 전선을 서로 바꾸어 이어 보세요. |
| SHORT_CIRCUIT | 부품을 거치지 않고 전지 양 끝이 바로 이어짐(합선) | 부품을 거치지 않고 전지의 양 끝이 바로 이어졌어요. … |
| ONE_BATTERY | B 회로판에 전지 1개만 이어서 작동은 하지만 전지 2개 밝기가 안 나옴(판정은 작동이라 힌트에서 따로 확인) | B 회로는 전지 2개를 모두 이어야 해요. 두 전지를 서로 다른 극끼리 한 줄로 이어 보세요. |

**힌트가 나오는 조건**
- 판정 순서: 전선 없음(NO_WIRES) → 합선(SHORT_CIRCUIT) → 고리 분석(끊김 BROKEN / 스위치 빠짐 SWITCH_MISSING / 같은 극 SAME_POLE / 버저 반대 BUZZER_REVERSED) → 스위치 열림(SWITCH_OPEN) → 작동하지만 B 회로판에 전지 1개(ONE_BATTERY). 앞에서 걸린 하나만 힌트로 나옵니다.
- **스위치를 닫아 둔 채** 막혔을 때만 힌트 버튼이 나옵니다. 예외로 SWITCH_OPEN(연결은 맞고 스위치만 열림)은 스위치가 열린 채로 나옵니다.
- 힌트가 나오지 않는 때: ② 만들기가 아닌 단계(① 예상, ③ 비교·이유, ④ 확인), 튜토리얼 중, 미션 1의 도전(같은 극끼리 잇기, 도전에는 따로 단계별 힌트가 있음), 회로가 이미 작동할 때.
- B 회로판에서 **전지 1개만 써서** 고리를 만들면 판정은 "작동(레벨 1)"이지만, 미션 완료 조건(레벨 2)을 못 채우므로 ONE_BATTERY 힌트를 줍니다. 시범 보기도 두 번째 전지를 서로 다른 극끼리 이어 넣을 때까지 안내합니다.

**힌트 시점**: 연결을 바꾸지 않고 **5초**가 지나면 회로판 아래에 **"힌트 보기" 버튼**이 나옵니다. 힌트는 저절로 뜨지 않고, 학생이 버튼을 눌러야 말풍선으로 펼쳐집니다. 힌트는 두 단계입니다. ① 먼저 상황에 맞는 **글 힌트**가 나오고, ② 글 힌트를 보고 **5초가 지나도 회로를 고치지 못했으면** 힌트 칸 오른쪽 아래에 "시범 보기"가 나오고, 누르면 **회로판 위 시범**을 봅니다. 시범은 **회로가 작동할 때까지 끝까지** 안내합니다. 힌트 칸에 "이렇게 해 보세요"와 남은 단계 전체(예: ① 전지 +와 버저 −를 잇는 전선을 눌러서 지워요 ② 전지 +와 버저 +를 전선으로 이어요 …)가 번호 목록으로 나오고, 지금 할 단계는 진하게 표시되며 회로판 위에서 튜토리얼처럼 반짝임과 화살표 커서로 보여 줍니다. 단계 순서는 필요 없는 전선 지우기 → 모자란 전선 잇기 → 스위치 닫기입니다. 학생이 한 단계를 하면 바뀐 회로판에서 남은 단계를 다시 계산하고, 다 고치면 시범이 끝납니다. 무엇을 보여 줄지는 지금 회로와 가장 적게 다른 정답 고리 회로를 찾아 정합니다(`circuit/nextFix.ts`). 두 단계 모두 힌트 횟수에 들어갑니다. 회로를 바꾸면 버튼과 힌트는 사라지고 다시 5초를 셉니다. 힌트를 본 횟수(버튼을 누른 횟수)와 전선을 잇거나 지운 횟수(시도)는 교사용 기록에 남습니다.

### 4-8. 회로 만들기 튜토리얼
- 미션 1의 ② 만들기에 처음 들어갈 때 자동으로 나옵니다. 기기마다 한 번만 자동으로 나오고, 이후에는 위쪽 "연결 방법 다시 보기"로 엽니다.
- 4단계: **전선 잇기 → 전선 지우기 → 스위치 누르기 → 이제 스스로!**
- 연습할 회로판만 밝게 드러나고, 반짝이는 고리와 시범 커서(큰 화살표)가 할 곳을 가리킵니다. 카드는 회로판 옆에 뜹니다.
- 학생이 실제로 해 보면 저절로 다음 단계로 넘어갑니다(**내가 한 조작으로만** 넘어감).

### 4-9. 도전! (선택 보충, 미션 1)
- ④ 확인 단계의 "도전! 더 해 보기 (선택)". B 회로의 전지 두 개를 **같은 극끼리** 이어 보는 활동입니다.
- 3단계 안내가 있고, 힌트를 토글로 하나씩 열어 볼 수 있습니다(정답을 바로 보여 주지 않음).
- 마치면: "전지를 늘리기만 해서는 안 되고, 서로 다른 극끼리 한 줄로 이어야 해요."
- 도전 중의 조작은 힌트·시도 횟수에 넣지 않습니다.

### 4-10. S5 마무리 (5단계 + 마치기, 모둠으로 할 때도 **각자** 진행)

| 단계 | 내용 | 규칙 |
|---|---|---|
| 1. 결과 모아 보기 | 미션별 "내 예상 / 실제 결과" 표 (자동 채움) | - |
| 2. 확인하기 | 미션에서 본 것을 되짚는 질문 3개(아래 표). 질문 앞에 1. 2. 3. 번호, 질문 사이 구분선. 세 질문에 다 답하면 정리 문장 4개가 노란 상자로 나옴. **"직렬연결" 용어가 처음 등장** | 질문마다 한 번만 고름. 고르면 고른 칸 바로 옆에 "정답이에요."(초록) 또는 "정답은 '더 밝았어요'예요."(빨강). 세 질문 모두 답해야 다음 |
| 3. 적용하기 | 응용 문제: "직렬연결한 전지를 2개에서 3개로 늘리면 전구의 밝기는 더 ( 밝아집니다 / 어두워집니다 )." (확인하기 1번과 겹치지 않도록, 정리 문장 "개수를 늘릴수록 더 밝게"를 적용해 보는 문제) | 한 번만 고름. 바로 "정답이에요."(초록) 또는 "정답은 '밝아집니다'예요."(빨강)와 해설. 맞든 틀리든 다음 가능 |
| 4. 오개념 점검 | O/X 3문항 | 한 번만 고름. 바로 정답·해설 |
| 5. 스스로 평가 | "전지 개수에 따른 전구의 밝기를 비교하고, 전지 개수에 따른 전기 회로의 특징을 설명할 수 있나요?" 잘할 수 있어요 / 조금 도움이 필요해요 / 더 연습이 필요해요 | 점수는 보여 주지 않음 |
| 마치기 (번호 없음) | 화면 전체가 환하게 되살아난 마을과 불꽃놀이 엔딩 "마을이 환하게 되살아났어요!" → "탐험 마치기" → "수고했어요, 탐험대!" | - |

**확인하기 질문 3개** (무엇과 비교하는지 드러나게 "전지 2개 회로 … 전지 1개 회로보다"로 물음)

| 번호 | 질문 | 보기 (정답 굵게) |
|---|---|---|
| 1 | 전지 2개 회로의 전구는 전지 1개 회로의 전구보다 어땠나요? | **더 밝았어요** / 더 어두웠어요 / 밝기가 같았어요 |
| 2 | 전지 2개 회로의 버저 소리는 전지 1개 회로의 버저 소리보다 어땠나요? | **더 컸어요** / 더 작았어요 / 크기가 같았어요 |
| 3 | 전지 2개 회로의 날개 달린 전동기는 전지 1개 회로의 전동기보다 어떻게 돌았나요? | **더 빨리 돌았어요** / 더 느리게 돌았어요 / 빠르기가 같았어요 |

**적용하기 해설**: "직렬연결한 전지의 개수를 늘릴수록 전기 에너지가 더 많이 공급돼서 전구가 더 밝아져요. 전지 1개보다 2개일 때 더 밝았던 것처럼, 3개면 2개일 때보다 더 밝아요."

**마무리 단계를 이렇게 정한 이유**
- 처음에는 7단계(생각 나누기 빈칸 쓰기, 설명하기, 확인해요 포함)였지만, 빈칸 쓰기와 설명하기가 같은 내용을 묻고, 확인해요(전지 2개가 더 밝다)도 설명하기 1번과 겹쳐서 정리했습니다.
- 빈칸 쓰기 단계는 빼고, 설명하기는 "확인하기"(미션에서 본 것 확인), 확인해요는 "적용하기"(전지 3개라는 새 상황에 적용)로 바꿨습니다.
- 마지막 "마치기"는 축제 엔딩 화면이라 단계 번호에 넣지 않고, 화면에는 1/5 ~ 5/5로 보입니다.
- 퀴즈(확인하기·적용하기·오개념 점검)는 모두 한 번만 고르고 바로 정답을 보여 줍니다. 처음 고른 답이 기록되어 교사가 학생의 처음 생각을 볼 수 있습니다. 스스로 평가는 퀴즈가 아니라서 바꿀 수 있습니다.

**확인하기 정리 문장(4개)**
1. 전지 여러 개를 서로 다른 극끼리 한 줄로 연결하는 방법을 전지의 직렬연결이라고 해요.
2. 전지 2개를 직렬연결하면 전지 1개를 연결했을 때보다 전구는 더 밝고, 버저의 소리는 더 크고, 날개 달린 전동기는 더 빠르게 돌아요.
3. 전지 2개를 직렬연결하면 전지 1개를 연결할 때보다 전기 에너지가 더 많이 공급돼요.
4. 직렬연결한 전지의 개수를 늘릴수록 전구를 더 밝게 할 수 있고, 버저로 더 큰 소리를 내거나 전동기를 더 빠르게 돌릴 수 있어요.

**오개념 점검 문항**

| 번호 | 문항 | 정답 | 해설 |
|---|---|---|---|
| ① | 전선이 연결되어 있기만 하면 전구에 불이 켜져요. | X | 스위치가 열리거나 전선이 끊기면 전기가 흐르지 않아 불이 켜지지 않아요. |
| ② | 전지의 개수가 늘어나면 전구는 무조건 더 밝아져요. | X | 전지의 개수가 늘어나도 같은 극끼리 연결하면 전구에 불이 켜지지 않아요. 여러 개의 전지는 서로 다른 극끼리 직렬연결해야 전구가 더 밝아져요(지도서 풀이 참고). |
| ③ | 전지 2개를 직렬연결한 회로의 버저는 전지 1개일 때보다 소리가 더 커요. | O | 전지 2개를 직렬연결하면 버저 소리가 더 커져요. |

## 6. 모둠 협업 규칙 (모둠으로 하기)

### 6-1. 기본 원칙

- **탐구는 함께, 정리는 각자.** 도입과 미션(예상·만들기·비교·확인)은 모둠이 한 화면을 함께 쓰고, 마무리(정리·평가)는 각자 합니다.
- **모둠의 상태는 하나.** 어느 화면에 있는지, 미션 단계, 회로판, 예상·○표·이유 같은 "공유 기록"은 모둠 전체에 하나만 있습니다. 한 명이 바꾸면 모든 기기에 같은 결과가 바로 반영됩니다.
- **"지금 들어와 있는 모둠원"이 기준.** 모두 동의, 모이기, 튜토리얼 기다리기는 지금 접속해 있는 모둠원만 셉니다. 연결이 끊긴 친구 때문에 나머지가 멈추지 않습니다.
- 모둠원마다 고유한 **색**이 있습니다(기기마다 같은 색). 위쪽 모둠 줄, 커서, 지도 캐릭터, 고른 답 표시, 쓰는 중 표시에 모두 같은 색이 쓰입니다.

### 6-2. 화면별로 함께 / 모두 동의 / 각자

| 화면·동작 | 방식 | 설명 |
|---|---|---|
| 도입 장면 넘기기(‹ ›) | 함께 | 한 명이 넘기면 모두 넘어감 |
| 도입 질문 3개(회로 조건 떠올리기, 전지 개수가 다른 까닭, 손 선풍기 예상) | **모두 동의** | 모두 같은 답이어야 빈칸이 채워지고 다음 장면으로 갈 수 있음 |
| 지도에서 돌아다니기 | 각자 | 캐릭터는 각자 움직이고, 친구 위치가 실시간으로 보임 |
| 움직이는 방법 튜토리얼(지도) | 각자 | 기기마다 따로 |
| 지도 위 반디 이야기("알겠어요") | 각자 | 각자 읽고 닫음. 본 기록도 기기마다 |
| 미션 시작 | 함께 + **모이기** | 모두 그 장소에 와야 눌리고, 한 명이 누르면 모두 함께 들어감 |
| 미션 이야기 창 | 각자 | 미션에 들어올 때마다 기기마다 뜨고 각자 닫음 |
| 미션 ① 예상 | **모두 동의** | 모두 같은 답일 때만 "이걸로 정했어요"가 눌림 |
| 처음 회로 만들기 튜토리얼 | 각자 + 기다리기 | 각자 연습용 회로판에서, 먼저 끝낸 사람은 기다림 화면 |
| 미션 ② 만들기(회로판) | 함께 | 누구나 A·B 회로판을 조작, 결과는 모두에게 같음 |
| ③ ○표 비교 | **모두 동의** | 모두 같은 답이어야 정해지고, 답이 갈리면 "확인하기"가 막힘 |
| ③ 이유 쓰기 | 함께 + **쓰는 중 잠금** | 한 명씩 쓰고, 쓰는 글자는 모두에게 실시간으로 보임 |
| ③ 확인하기(채점) | 함께 | 한 명이 누르면 모두에게 채점과 모범 답안이 뜸 |
| ④ 축하 창 "결과 보기" | 함께 | 한 명이 누르면 모두 확인 화면으로 넘어감 |
| ④ 도전(같은 극끼리) | 함께 | 회로판과 힌트 열기가 모두에게 같음 |
| 지도로 돌아가기 / 지도로 나가기 | 함께 | 한 명이 누르면 모두 지도로 |
| 마무리로 가기 | 각자 | 누른 사람만 마무리 화면으로 넘어감. 안 누른 친구는 지도에 그대로 |
| 마무리 5단계·마치기 | 각자 | 단계 넘기기, 고르기, O/X, 스스로 평가, 마치기 모두 각자. 친구 답은 보이지 않음 |
| 나가기 | 각자 | 누른 기기만 처음 화면으로. 그 기기 기록만 지우고 모둠 기록은 서버에 남음 |
| 소리 켜기·끄기, 어둡게 보기, 지도/탐험 보기 | 각자 | 기기마다 따로 |

### 6-3. 모두 동의

- 각자 선택지를 고르면, 선택지 옆에 고른 모둠원의 **색 동그라미(이름 첫 글자)**가 붙습니다. 마우스를 올리면 이름이 보입니다.
- 지금 들어와 있는 모둠원이 **모두 같은 답**을 골라야 그 답으로 정해집니다. 미션 예상은 같은 답이 된 뒤 "이걸로 정했어요"를 눌러야 정해지고, 나머지 문제는 같아지는 순간 자동으로 정해집니다.
- 한 번 정해진 뒤에 누가 답을 바꾸면, 다시 모두 같아질 때까지 다음으로 넘어갈 수 없습니다. 도입 빈칸도 "?"로 돌아갑니다.
- **도입에서만** "모둠원 모두 같은 답을 골라야 정할 수 있어요 (1/2명)" 안내 문구가 보입니다. 모두 동의를 처음 만나는 곳이라서입니다. 미션에서는 색 동그라미만 보입니다.
- 모둠이 바뀌거나, 미션에 들어가고 나올 때(다시 하기 포함)는 지난번에 고른 답이 모두 지워집니다. 지난 답이 남아 새 판에서 저절로 정해지는 일을 막기 위해서입니다.
- 혼자 할 때는 고르면 바로 정해집니다.

### 6-4. 모이기 (미션 시작)

- 미션 장소에 도착하면 상황 창 아래에 모둠원 이름이 나오고, 도착한 사람은 ✓, 아직인 사람은 "· 오는 중"으로 보입니다. "모둠원이 모두 모이면 시작할 수 있어요 (1/2명)"도 함께 보입니다.
- 장소 가운데에서 일정 거리(지도 좌표 75) 안에 들어오면 도착으로 봅니다. 모든 기기가 같은 좌표로 같은 판단을 합니다.
- 모두 도착해야 "미션 시작!"이 눌리고, 한 명이 누르면 모두 함께 미션에 들어갑니다.
- **모두 부르기**: 도착한 사람이 누르면 친구 화면 위쪽에 "○○ 친구가 가로등에서 기다려요 [함께 가기]"가 뜹니다. "함께 가기"를 누르면 그 장소로 바로 이동합니다. ✕로 알림을 닫을 수 있습니다.
- 완료한 미션의 "다시 하기", "결과 확인하기"도 같은 모이기 규칙을 따릅니다.

### 6-5. 처음 회로 만들기 튜토리얼 (각자 연습 후 함께 시작)

- 미션 1의 ② 만들기에 처음 들어가면, 모둠원마다 회로판 옆에 **"연습용 회로판 (나만 보여요)"**가 붙은 연습 회로판이 나옵니다.
- 연습용 회로판은 그 기기에만 있어서 친구의 조작과 섞이지 않고, 미션 기록(시도·힌트 횟수)에도 남지 않습니다. 튜토리얼은 **내가 한 조작으로만** 다음 단계로 넘어갑니다.
- 먼저 끝낸 사람은 화면 전체가 뿌옇게 덮이고 "친구들이 회로 연결 방법을 익히고 있어요 / 1/2명 끝냈어요. 모두 끝나면 함께 회로를 만들어요."가 뜹니다.
- 모두 끝내면 덮개가 걷히고 모둠 회로판에서 함께 만듭니다.
- 튜토리얼은 기기마다 한 번만 자동으로 뜹니다. 이미 해 본 기기는 바로 시작합니다. 나중에 "연결 방법 다시 보기"로 연 튜토리얼은 친구를 기다리게 하지 않습니다.

### 6-6. 쓰는 중 잠금

- 미션 ③의 생각 적기 칸에 누군가 **글자를 넣기 시작하면**, 다른 친구 화면에는 그 칸이 쓰는 사람의 색 테두리로 잠기고 "민지 쓰는 중…" 표시가 뜹니다. 칸을 누르기만 해서는 잠기지 않습니다.
- 쓰는 글자는 한 글자씩 모두에게 실시간으로 보입니다. 쓰는 사람이 칸을 벗어나거나 **5초 동안 글자를 넣지 않으면** 잠금이 풀려 다른 친구가 이어 쓸 수 있습니다(태블릿은 다른 곳을 눌러도 칸에서 벗어나지 않을 때가 있어서).
- 잠긴 칸을 눌러 봐도 잠금을 가져가지 않습니다. 예전에는 누르기만 해도 쓰는 사람으로 잡혀서, 쓰던 친구가 갑자기 막히거나 친구가 다 쓰고 나가도 칸이 계속 잠기는 문제가 있었습니다.
- 두 사람이 정확히 동시에 쓰기 시작하면 모든 기기가 같은 규칙으로 한 사람만 쓰게 정합니다.
- 다음 단계로 넘어가 칸이 사라지면 잠금도 자동으로 풀립니다.

### 6-7. 친구가 무엇을 하는지 보이는 기능

| 기능 | 보이는 곳 | 내용 |
|---|---|---|
| 위쪽 모둠 줄 | 도입·지도·미션 (마무리에서는 숨김) | 모둠 이름, 지금 들어와 있는 모둠원(색 점, 나는 "(나)"), 연결 상태("연결하는 중…", "연결이 끊겼어요…") |
| 친구 커서 | 미션 화면 전체 | 친구 색 화살표와 이름표. 화면 크기가 달라도 같은 버튼·같은 단자를 가리키도록 "영역 안의 요소와 그 안의 위치"로 맞춤 |
| 친구가 끄는 전선 | 회로판 | 친구가 전선을 끌고 있으면 친구 색 점선으로 보임 |
| 회로판 조작 알림 | 회로판 왼쪽 위 | "지아: 전선을 이었어요 / 전선을 지웠어요 / 스위치를 눌렀어요"가 3초 동안 (연습용 회로판에는 안 뜸) |
| 지도 위 캐릭터 | 지도 | 친구가 고른 캐릭터가 친구 색 발밑 고리와 이름표를 달고 실시간으로 움직임. 내 캐릭터 위에도 이름표 |
| 고른 답 표시 | 모두 동의 문제 | 선택지 옆 색 동그라미 |
| 쓰는 중 표시 | 서술형 칸 | "민지 쓰는 중…" |
| 튜토리얼 기다리기 | 미션 화면 | "1/2명 끝냈어요" |

### 6-8. 연결과 동기화 규칙

- **늦게 들어온 친구**: 서버에 저장된 모둠 상태로 시작하고, 이미 들어와 있는 친구 기기에서 지금 화면을 받아 맞춥니다.
- **놓친 조작 맞추기**: 모둠 기기 중 하나(지금 들어와 있는 사람 중 기기 id가 가장 앞선 기기)가 15초마다 전체 상태를 보냅니다. 3초 안에 직접 조작한 기기는 자기 조작이 덮이지 않게 이 맞추기를 잠깐 건너뜁니다.
- **실시간 표시**(커서·캐릭터·쓰는 중·고른 답)는 저장하지 않는 가벼운 메시지로 초당 약 15번까지 보내고, 3초마다 한 번씩 다시 알립니다. 9초 동안 소식이 없는 친구는 화면에서 사라집니다.
- **새로고침**해도 같은 모둠으로 다시 들어갑니다. 마무리에 들어간 것도 기기에 기억해서 새로고침 뒤에도 마무리 화면이 이어집니다.
- **캐릭터 정보**: 모둠에 들어갈 때 이름과 함께 고른 캐릭터를 모둠원 정보로 알려서, 친구 기기에서도 같은 모습으로 그립니다.
- **힌트 횟수**는 같은 힌트를 여러 기기가 여러 번 세지 않도록 모둠에서 한 기기만 셉니다.
- **브라우저 탭이 뒤에 숨거나 화면이 꺼지면** 브라우저가 알림을 늦게 보내서, 잠시 뒤 그 친구가 "오는 중"으로 보이거나 사라질 수 있습니다. 다시 화면을 켜면 돌아옵니다.

### 6-9. 모둠을 처음부터 다시 하려면

학생 화면의 "나가기"는 그 기기의 기록만 지웁니다. 모둠의 진행 기록은 서버에 남아 있어서, 같은 모둠을 다시 고르면 하던 곳부터 이어서 합니다(수업 중 새로고침이나 기기 바꾸기에 대비). 모둠을 처음부터 다시 하려면 교사가 교사용 화면의 **모둠 관리**에서 그 모둠을 지우고 다시 만듭니다. 학생 화면에는 모둠 전체 기록을 지우는 버튼을 일부러 넣지 않았습니다(수업 중 실수로 지우는 일을 막기 위해).

## 7. 교사용 화면 (`/teacher`)

### 7-1. 들어가기와 화면 구성

- 주소: 게임 주소 뒤에 `/teacher` (예: `http://localhost:3200/teacher`).
- **로그인**: 흰 상자 가운데에 반디 그림, "불빛 탐험대", "선생님용 화면", 비밀번호 칸, "들어가기". 비밀번호는 서버 설정(환경 변수 `TEACHER_PIN`)으로 정하고, 틀리면 "비밀번호가 맞지 않습니다."가 뜹니다.
- **왼쪽 사이드바 메뉴**: 한눈에 보기 / 모둠 진행 / 기록 / 모둠 관리 / 평가 기준. 누른 메뉴의 화면만 보여서 길게 스크롤하지 않아도 됩니다. 좁은 화면에서는 위쪽 가로 메뉴로 바뀝니다.
- 사이드바 아래에 마지막으로 불러온 시각과 "10초마다 새로 불러와요."가 보입니다.
- **10초마다 자동으로 새로 불러오고**, 최근 12시간 안에 저장된 기록(오늘 수업)만 보여 줍니다. 모둠 진행·기록은 **최근에 게임을 한(마지막으로 저장된) 순서**로 보여 주고, 각 모둠에 "마지막 활동 10:08"처럼 시각을 함께 적습니다. 모둠 관리의 모둠 목록은 이름 순(1모둠, 2모둠 … 10모둠)입니다.
- 기록이 하나도 없으면 "오늘(최근 12시간) 기록된 모둠이 없어요."가 보입니다.
- 점수나 상·중·하를 자동으로 매기지 않습니다. 근거 자료만 보여 주고 판단은 교사가 합니다.

### 7-2. 한눈에 보기 (자동 통계)

선생님이 꼭 봐야 할 세 가지만 보여 줍니다. 맨 위는 가로로 늘어선 숫자 카드 4칸(큰 숫자 "3/5", 비율 %, 얇은 막대. 미션 세 칸은 모둠 수, 마무리 완료는 사람 수), 아래 두 가지는 **나눠진 가로 막대**입니다. 문항마다 막대 한 줄을 학생(모둠)이 고른 답의 비율로 나눠, 무엇을 골랐는지 한눈에 보입니다. 정답 조각은 맨 앞에 차분한 초록, 오답은 대시보드 바탕과 어울리는 모래색(진하게·연하게)이고, 막대 아래에 색 점과 보기 글(정답은 초록 점), 오른쪽에 "정답 60% · 3/5명"이 나옵니다. 문항 이름이나 막대 조각에 마우스를 올리면 문항 전체와 인원·비율이 보입니다.

| 그래프 | 줄 | 무엇을 셌나 |
|---|---|---|
| **숫자 카드** | 가로등 완료·광장의 안내 종 완료·언덕의 풍차 완료 | 미션마다 완료한 모둠 / 전체 모둠 |
| | 마무리 완료 | 마무리 마지막 화면에서 "탐험 마치기"까지 누른 사람 / 마무리 기록 인원 (모둠으로 한 곳은 학생마다, 혼자 한 모둠은 하나) |
| **미션별 예상 · 모둠이 고른 답** | 가로등·광장의 안내 종·언덕의 풍차 | ① 예상 보기 세 개를 고른 모둠 수 (정답: 전지 2개일 때 더 ~) |
| **마무리 퀴즈 · 학생이 고른 답** | 확인하기: 전구 밝기·버저 소리·전동기 빠르기 | 마무리 2단계 세 문항에서 보기 세 개를 고른 사람 수 (정답 "더 ~했어요", 처음 고른 답) |
| | 적용하기: 전지 3개로 늘리면 | 마무리 3단계에서 밝아집니다 / 어두워집니다를 고른 사람 수 (정답 밝아집니다, 처음 고른 답) |
| | 오개념 1·2·3 (문항 요약) | 마무리 4단계 문항마다 ○ / ×를 고른 사람 수 (처음 고른 답) |

○표 비교, 힌트 횟수, 스스로 평가 같은 자세한 내용은 **모둠 진행**과 **기록** 메뉴에서 봅니다.

### 7-3. 모둠 진행

모둠마다 한 줄인 표, **8모둠씩 페이지**로 나뉩니다.

| 칸 | 뜻 |
|---|---|
| 모둠 | 모둠 이름 (혼자 하기는 학생 이름) |
| 마지막 활동 | 마지막으로 기록이 저장된 시각 (이 순서로 정렬, 최근 것이 위) |
| 지금 위치 | 입장 / 도입 / 마을 지도 / 미션 · 장소 · 단계(① 예상, ② 만들기, ③ 비교·이유, ④ 확인) / 마무리, 다 마쳤으면 "탐험 마침" |
| 완료한 미션 | 미션을 완료한 장소 수 / 3 (가로등·안내 종·풍차) |
| 가로등·광장의 안내 종·언덕의 풍차 힌트/시도 | 미션마다 힌트를 본 횟수 / 전선을 잇거나 지운 횟수. 힌트 3번 이상이면 빨간 굵은 글씨 |

### 7-4. 기록 (탭 2개)

**① 모둠 기록** — 모둠마다 표 두 개(도입 표, 미션 표), **3모둠씩 페이지**

- 맨 위: 모둠 이름과 마지막 활동 시각. 최근에 게임을 한 모둠이 먼저 나옵니다.
- **도입 표**: 열은 질문 세 개(불이 켜지는 회로 / 전지 개수가 다른 이유 / 손 선풍기 바람 예상, 마우스를 올리면 실제 질문 전체), 아래 "고른 답" 한 줄. 세 칸 모두 맞음·틀림(✓·✗, 칸 색)을 표시합니다. 정답: 끊기지 않게 / (가) 필요한 전기의 양이 달라서 / (나) 전지 2개를 넣을 때. "(다) 잘 모르겠어요"는 색 없이 글만. 학생 화면에서는 도입 때 정답을 보여 주지 않습니다.
- **미션 표**: 열은 미션 세 개(가로등 / 광장의 안내 종 / 언덕의 풍차, 제목 옆에 완료 / 진행 중 / 잠김), 줄은 아래 항목(줄 이름에 마우스를 올리면 무엇인지 설명이 보임). 같은 항목을 미션끼리 가로로 바로 비교할 수 있고, 긴 글은 칸 안에서 줄바꿈됩니다.

| 항목 | 내용 |
|---|---|
| 예상 | 고른 예상 전체 문장, 앞에 ✓(초록, 실제 결과와 같음) / ✗(빨강) |
| 회로 완성 | A ✓/✗, B ✓/✗ (각 회로를 한 번이라도 정상으로 만들었는지) |
| 결과 | 실험 뒤 ○표 한 말(예: 밝다)과 ✓/✗ |
| 힌트 / 시도 | "2 / 7" = 힌트 본 횟수 / 전선을 잇거나 지운 횟수 (힌트 3번 이상이면 빨강) |
| 도전 과제 (가로등만) | 같은 극끼리 연결해 보기: 미도전 / 도전 중 / 도전 완료 |
| 모둠 이유 | 결과가 그렇게 나온 까닭을 모둠이 쓴 글 전체 |

맞음·틀림은 글자 앞의 가는 선 ✓·✗와 **칸 바탕색**(맞음 연한 초록, 틀림 연한 빨강)으로 보여 줍니다. 회로 완성은 A·B를 모두 이었으면 초록, 미션을 마쳤는데 못 이은 게 있으면 빨강입니다. 아직 답이 없으면 흰 칸에 회색 "-"입니다.

**② 개인 마무리 기록** — 한 사람이 한 줄, **10명씩 페이지**. 모둠으로 한 곳은 학생 한 명씩, 혼자 한 모둠은 모둠 이름으로 한 줄입니다.

모둠 기록과 같은 표 모양입니다. 문항마다 칸을 나눠 칸 하나에 ✓·✗ 아이콘만 두고, **맞은 칸은 연한 초록, 틀린 칸은 연한 빨강**으로 채웁니다(아직 답이 없으면 흰 칸에 "-"). 문항 이름에 마우스를 올리면 실제 문항 전체가 보입니다.

| 칸 | 내용 |
|---|---|
| 모둠 / 이름 | 모둠 이름, 학생 이름 |
| 진행 | "3/5단계" 또는 "탐험 마침" |
| 확인하기 (전구 밝기 / 버저 소리 / 전동기 빠르기) | 세 문항 각각 맞음·틀림 (처음 고른 답) |
| 적용하기 (전지 3개) | 맞음·틀림 (처음 고른 답) |
| 오개념 점검 (1번 / 2번 / 3번) | 문항마다 맞음·틀림 (처음 고른 답) |
| 스스로 평가 | 고른 문장 |

### 7-5. 모둠 관리

- **모둠 만들기**: "만들 모둠 수"(1~12)를 정하고 "모둠 만들기". 이름은 "1모둠, 2모둠 …"으로 자동으로 붙고, 이미 있는 모둠 다음 번호부터 이어집니다(예: 1~6모둠이 있으면 7모둠부터). 한 수업(12시간)에 최대 12모둠.
- 만든 모둠은 칩으로 이름 순 정렬되어 보이고, 학생 입장 화면의 "모둠으로 하기" 목록에도 같은 순서로 나옵니다.
- **모둠 지우기**: 칩의 ✕ → 앱 모양 확인 창 "2모둠을 지울까요? / 이 모둠의 기록도 함께 지워지고, 학생 화면의 모둠 목록에서도 사라져요." → 빨간 "지우기". 지운 모둠은 진행 기록도 함께 사라집니다. 모둠을 처음부터 다시 하고 싶을 때도 지우고 다시 만듭니다.
- 모둠을 만들 때 서버가 모둠마다 처음 상태(도입 화면에서 시작)와 실시간 채널 이름을 미리 만들어 둡니다.

### 7-6. 평가 기준

- 지도서 평가 요소 3개: 전지 1개 회로와 전지 2개 직렬 회로에서 전구의 밝기 비교하기(과정·기능), 전지의 개수에 따른 전구의 밝기 차이 말하기(지식·이해), 전지의 개수에 따른 회로의 특징을 비교하는 활동에 적극적으로 참여하기(가치·태도).
- 요소마다 "보는 내용", 게임에서 찾을 수 있는 "근거" 기록, 상·중·하 기준을 보여 줍니다.
- 평가 요소와 보는 내용은 명세서(지도서 평가 요소)를 따랐고, **상·중·하 문장은 임시 예시 문장**이라 지도서 원문으로 바꿔야 합니다.

## 8. 기록되는 데이터 (학습 기록)

모둠 하나의 기록 전체를 한 덩어리(JSON)로 저장합니다. 혼자 하기는 한 사람이 한 "모둠"입니다.

| 영역 | 기록 내용 |
|---|---|
| 기본 | 모둠 id, 모둠 이름, 지금 화면·미션·단계 |
| 도입 | 회로 조건 떠올리기(처음 고른 답의 맞음/틀림), 전지 개수가 다른 까닭, 손 선풍기 예상 |
| 미션별 | 상태(잠김/진행/완료), 예상, A·B 정상 연결 여부, ○표 비교, 모둠 이유(글), 힌트 본 횟수, 시도(전선 잇기·지우기) 횟수, 완료 시각, 마지막 회로판, 도전 여부, 확인하기(채점) 여부 |
| 마무리 | 혼자 하기: 모둠 기록에. 모둠으로 하기: **학생별**로 확인하기 3답(처음 고른 답), 적용하기(처음 고른 답), 오개념 3문항 맞음/틀림(처음 고른 답), 스스로 평가, 진행 단계, 마침 여부 |

**저장 위치**

| 어디에 | 무엇을 | 언제 |
|---|---|---|
| 학생 기기(브라우저 localStorage) | 게임 상태 전체, 들어가 있는 모둠, 고른 캐릭터, 소리 끄기 설정, 튜토리얼을 본 적 있는지, 지도 이야기를 본 기록(모둠), 마무리에 들어갔는지(모둠) | 바뀔 때마다 바로 |
| 서버(Supabase DB `group_sessions` 표, 모둠마다 한 줄) | 모둠의 게임 상태 전체(위 표의 기록) | 서버 저장이 켜져 있으면 바뀐 뒤 2초에 한 번 모아서 |
| 저장하지 않음 | 커서, 지도 캐릭터 위치, 쓰는 중, 고른 답 표시, 튜토리얼 중 | 실시간으로만 주고받음 |

- 인터넷이 잠깐 끊겨도 수업은 계속되고, 기록은 기기에 남아 있다가 다음 변경 때 다시 보냅니다.
- **처음 고른 답만 기록**하는 항목: 회로 조건 떠올리기, 마무리 확인하기·적용하기·오개념 점검 (학생의 처음 생각을 근거로 남기기 위해). 스스로 평가는 퀴즈가 아니라서 바꿀 수 있습니다.
- **다시 하기**를 하면 그 미션 기록은 새로 한 것으로 바뀝니다(이전 기록은 남지 않음).
- 개인정보는 학생이 입력한 이름(별명 가능) 외에는 받지 않습니다.

## 9. 소리와 화면 연출

### 9-1. 소리 (음원 파일 없이 Web Audio로 직접 합성)

| 소리 | 언제 | 특징 |
|---|---|---|
| 배경 음악 | 처음 누르거나 입력한 뒤부터 계속. **미션 화면(회로 만들기 3곳)에서는 꺼짐** | 오르골 느낌의 잔잔한 반복곡(빠르기 92). 미션 화면에서는 버저 종소리·전동기 소리·불 켜지는 소리를 잘 듣고 비교하도록 끄고, 지도로 나오면 다시 연주. 브라우저 탭을 여러 개 열어도 지금 보고 있는 탭 한 곳에서만 연주 |
| 버튼 "톡" | 모든 버튼을 누를 때 | 낮고 짧은 소리 (높은 소리는 귀에 거슬려서 뺌) |
| 창 열림 "띠링" | 확인 창, 장소 상황 창이 뜰 때 | 짧은 두 음 |
| 전구 켜짐 | 전구가 켜질 때 | 전지 2개 쪽이 더 높고 큼 |
| 버저 종소리 "딩~" | 버저가 작동하는 동안 2초마다 | A·B가 1초씩 번갈아 울림. 같은 소리이고 크기만 다름(전지 2개 쪽이 확연히 큼). 큰 소리가 찢어지지 않게 리미터를 씀 |
| 전동기 "위잉" | 날개 달린 전동기가 도는 동안(② 만들기·도전). 그 밖의 단계에서는 바뀌는 순간 1.5초만 | 모터 소리(낮은 톱니파) + 날개가 바람을 가르는 "휘휘" 소리. 전지 2개(빨리 돎)는 더 높고 확연히 크며, "휘휘"도 날개 빠르기에 맞춰 더 잦음(1.25번/초 → 6번/초) |
| 미션 성공 | ④ 확인에 들어올 때 | 올라가는 세 음 |

- **소리 버튼**: 오른쪽 위에서 언제든 끄고 켤 수 있고 기기에 기억합니다. 끄면 배경 음악과 모든 효과음이 함께 꺼집니다. 이야기 창이나 축하 장면이 떠 있어도 누를 수 있게 맨 위에 떠 있습니다.

### 9-2. 화면 연출

- **오프닝**: 별, 반딧불, 어두운 마을이 차례로 떠오르고 제목이 나타나는 애니메이션.
- **도입 컷 애니메이션**: 장면마다 움직이는 그림(어두워지는 마을, 반디 등장, 끊기지 않은 회로, 손 선풍기·손전등·리모컨 그림 등). 장면 전환은 부드럽게 미끄러짐.
- **캐릭터 고르기 무대**: 밤하늘 별, 무대 조명, 캐릭터별 움직임(통통·깡충·살랑·둥실·파닥·쿵쿵), 넘기는 방향으로 스르륵 들어오는 효과.
- **걷기**: 한 발씩 번갈아 디디고 몸이 디딘 발 쪽으로 기우는 걸음(마을 동물도 같은 걸음).
- **반디**: 위아래로 살랑이며 떠 있고, 말풍선 글이 한 글자씩 써짐.
- **할 곳만 밝히기(스포트라이트)**: 할 곳만 밝고 나머지는 어둡게.
- **되살아남**: 장소가 서서히 밝아지고 움직이기 시작함.
- **축하 창**: 화면이 살짝 어두워지고 반디가 날아와 축하.
- **마무리 엔딩**: 화면 전체에 환하게 되살아난 마을, 불꽃놀이, 축제 줄장식, 반딧불.
- **그림체**: 모든 그림(마을, 캐릭터, 부품, 아이콘)을 이미지 파일 없이 SVG 도형으로 직접 그려 하나의 그림체로 통일. 이모지를 쓰지 않음.
- **창 애니메이션**: 팝업은 살짝 떠오르며 나타나고, 모든 떠 있는 창에 ✕가 있어 언제든 닫을 수 있음.

## 10. 사용성·접근성·안전·개인정보

### 10-1. 사용성 (초등학생과 태블릿 기준)
- 모든 버튼과 선택지는 손가락으로 누르기 쉬운 크기(최소 44px 높이)로 만들었습니다.
- 글자는 기본 18px로 크게, 한 화면에 한 가지 할 일만 보이게 했습니다(마무리는 한 단계씩).
- 키보드로도 할 수 있습니다: 캐릭터 고르기 ←/→·Enter, 도입 ←/→, 지도 방향키·WASD·Enter, 확인 창 Esc(취소), 확인 창이 뜨면 "취소"에 먼저 초점(실수로 Enter를 눌러도 기록이 지워지지 않게).
- 진행을 막는 조건이 있으면 버튼이 흐리게 바뀌어 눌리지 않고, 할 일을 안내 문구나 단계 칩으로 보여 줍니다.
- 언제든 "지도"로 돌아가거나 "나가기"로 처음 화면에 갈 수 있고, 하던 미션은 다시 들어오면 이어서 합니다.

### 10-2. 접근성
- 맞음·틀림, 친구 구분 등을 **색만으로 알리지 않고** ✓·✗ 기호, 이름 첫 글자, 글자를 함께 씁니다(교사용 기록 표는 칸 색 + ✓·✗ 아이콘). 교사용 한눈에 보기의 나눠진 막대는 정답 조각을 늘 맨 앞에 두고 오른쪽에 "정답 60%"를 글로 적어, 색을 구분하기 어려워도 정답 비율을 알 수 있습니다.
- ○·×, ✓·✗는 글꼴마다 크기가 달라서 같은 크기로 그린 그림(SVG)으로 보여 줍니다.
- 버튼·그림에 화면 읽기용 이름(aria-label)을 붙였고, 상태 변화 안내는 status 영역으로 알립니다.
- 움직임 줄이기 설정을 켠 기기에서는 화면 자동 스크롤을 부드러운 효과 없이 바로 옮깁니다.
- 어둡게 보기로 회로판 대비를 높여 밝기 차이를 보기 쉽게 합니다.

### 10-3. 안전 교육
- 입장할 때 안전 약속 3가지를 모두 체크해야 시작합니다.
- 미션 화면 아래에 늘 안전 문구가 보입니다: "전기 부품을 만질 때는 절연 장갑을 끼고, 젖은 손으로 만지지 않아요. 진짜 콘센트 전기로는 절대 실험하지 않아요!" + 미션별 주의(전구 유리, 전선 집게, 전동기 날개).
- 안전 장갑 그림(초록)으로 안전 약속을 눈에 띄게 했습니다.

### 10-4. 개인정보
- 학생에게 받는 정보는 화면에 보일 이름(별명 가능) 하나뿐입니다. 로그인, 이메일, 학번을 받지 않습니다.
- 기록은 최근 12시간 수업분만 교사 화면에 보이고, 교사 화면은 비밀번호로 보호됩니다.
- 서버 전용 키는 브라우저로 보내지 않고, DB는 브라우저에서 직접 읽거나 쓸 수 없게 막았습니다.

| 서버 저장 | Supabase PostgreSQL (`group_sessions` 표 하나), Next.js Route Handler가 서버 전용 키로 읽고 씀 |
| 테스트 | Vitest 단위 테스트 (회로 판정, 단계 규칙, 동기화 규칙, 모두 동의·쓰는 중 잠금, 교사 통계 등 84개) |

**핵심 설계**
- **상태 변경은 reducer 하나로**: 모든 게임 상태 변화는 한 곳(결정적 reducer)에서만 일어납니다. 시각·id는 action에 담아 보내서, 같은 action을 모둠의 모든 기기에 보내면 화면이 똑같아집니다.
- **두 층 동기화**: ① 공유 기록(회로·답·단계)은 action을 모든 기기에 보내 저장까지 하고, ② 실시간 존재감(커서·캐릭터 위치·쓰는 중·고른 답 표시)은 저장하지 않는 가벼운 메시지로 초당 약 15번 보냅니다.
- **판정은 순수 함수**: 회로 판정은 화면과 분리된 함수라서 테스트로 검증합니다.
- **문구는 한 파일에**: 학생 화면 문구를 모두 `src/data/strings.ts`에 모아, 교사가 문구만 고치기 쉽습니다.
- **보안**: 서버 전용 키는 브라우저에 보내지 않고, DB는 브라우저에서 직접 접근할 수 없게 막았습니다(RLS). 교사 API는 비밀번호로 보호합니다.
- **3단계 구성**: 환경 설정 없이도 1단계(브라우저 저장만)로 동작하고, 설정을 넣으면 2단계(서버 저장·교사 화면), 3단계(모둠 실시간)가 켜집니다.

## 12. 교육적 설계 의도 (보고서용)

- **POE 순서 지키기**: 예상을 먼저 정하고 바꿀 수 없게 해 학생의 처음 생각을 기록합니다. 확인 전에는 정답·원리를 보여 주지 않고, 용어("직렬연결")는 관찰을 모두 마친 뒤 마무리에서 처음 제시합니다.
- **직접 만들며 관찰**: 부품 위치는 고정하고 연결만 맡겨, 조작의 어려움보다 "전지 개수에 따른 차이" 관찰에 집중하게 했습니다. 두 회로를 나란히 놓아 바로 비교할 수 있습니다.
- **같은 원리, 세 가지 현상**: 전구(빛)·버저(소리)·전동기(움직임)에서 같은 결과를 반복 확인해 일반화하도록 미션을 배치했습니다. 이유 쓰기 질문도 "앞 미션과 비슷한 점"을 묻도록 점점 바뀝니다.
- **막혔을 때 단계적 도움**: 5초 멈추면 "힌트 보기" 버튼이 나와 학생이 원할 때 상황에 맞는 힌트를 펼쳐 보고, 도움말 토글, 도전 활동의 단계별 힌트로 스스로 해결하게 돕습니다. 힌트 횟수는 교사에게 도움이 필요한 모둠을 알려 주는 근거가 됩니다.
- **오개념 다루기**: "전선만 연결되면 켜진다", "전지가 많으면 무조건 밝다"를 O/X로 점검하고, 도전 활동(같은 극끼리 잇기)으로 "연결 방법"의 중요성을 직접 확인하게 했습니다.
- **협력과 개인 책임의 균형**: 탐구(도입·미션)는 모둠이 함께 하되 "모두 동의"로 모둠원 모두가 의견을 내게 하고, 정리·평가(마무리)는 각자 하게 해 개인별 이해도를 확인합니다.
- **게임 요소**: 이야기, 돌아다니는 마을, 되살아나는 장소, 축제 엔딩으로 동기를 높이고, 안전 약속을 시작과 미션 화면에 넣어 실제 실험 안전 교육과 연결했습니다.
- **교사 지원**: 자동 채점·점수 대신 근거 자료와 통계를 보여 주어 교사가 지도서 평가 기준으로 판단하도록 했습니다.

## 13. 수업 운영 방법 (선생님용 순서)

**수업 전**
1. 게임 주소(배포 주소 또는 교실 컴퓨터 주소)를 정하고, 학생 기기에서 열리는지 확인합니다.
2. 교사용 화면(`/teacher`)에 비밀번호로 들어가 **모둠 관리 → 모둠 만들기**로 모둠 수만큼 만듭니다(예: 6모둠).
3. 학생 기기 소리 크기를 확인합니다(버저 미션은 소리 크기를 비교하는 활동).

**수업 중 (지도서 4차시 흐름)**
1. 학생이 게임 주소로 들어와 **모둠으로 하기 → 우리 모둠 → 내 이름 → 안전 약속 → 캐릭터 고르기**를 하고 들어옵니다. 기기가 모자라면 한 기기로 **혼자 하기**도 할 수 있습니다.
2. 도입(이야기 5장면)에서 회로 조건을 떠올리고 전지 제품 이야기로 예상합니다.
3. 마을 지도에서 모둠원이 함께 장소로 이동해 미션 1 → 2 → 3을 해결합니다(예상 → 만들기 → 비교·이유 → 확인).
4. 교사는 **한눈에 보기**와 **모둠 진행**으로 어느 모둠이 어디에 있는지, 힌트를 많이 쓴(빨간 숫자) 모둠이 어디인지 보며 순회 지도합니다.
5. 세 미션을 마친 학생은 각자 **마무리 5단계**를 합니다.

**수업 뒤**
1. **기록 → 모둠 기록**에서 모둠의 도입 답, 미션별 예상·회로 완성·결과·모둠 이유를 확인합니다(맞은 칸 초록, 틀린 칸 빨강).
2. **기록 → 개인 마무리 기록**에서 학생별 확인하기·적용하기·오개념 점검 맞음·틀림과 스스로 평가를, **한눈에 보기**에서 반 전체가 어떤 답을 많이 골랐는지(나눠진 막대)를 확인합니다.
3. **평가 기준** 메뉴의 평가 요소와 근거를 참고해 교사가 판단합니다.
4. 같은 반을 다시 하거나 다음 반 수업 전에는 모둠을 지우고 새로 만듭니다(기록은 최근 12시간 것만 보임).

## 15. 한계와 남은 일

- 교사용 평가 기준(상·중·하) 문장은 임시 문장이라 지도서 문장으로 바꿔야 합니다.
- 태블릿 실기기에서 글자·버튼 크기, 움직임의 부드러움, 마무리 7분 안에 끝나는지 확인이 필요합니다.
- 학생 화면의 "나가기"는 그 기기의 기록만 지웁니다. 모둠으로 할 때는 진행 기록이 서버에 남아 있어서, 같은 모둠을 다시 고르면 하던 곳부터 이어서 합니다. 모둠을 처음부터 다시 하려면 교사가 교사용 화면의 모둠 관리에서 그 모둠을 지우고 다시 만듭니다. 학생 화면에는 모둠 전체 기록을 지우는 버튼을 일부러 넣지 않았습니다(수업 중 실수로 지우는 일을 막기 위해).
- 같은 와이파이의 다른 기기에서 http 주소로 접속할 때를 위해 보안 연결(https)이 아니어도 동작하도록 만들었지만, 실제 수업 배포는 https 주소를 권장합니다.
