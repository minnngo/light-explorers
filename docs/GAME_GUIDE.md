## 2. 세계관과 이야기

- **무대**: 전지의 힘으로 불을 밝히는 "반짝마을". 오늘 밤은 일 년에 한 번 열리는 불빛 축제 날입니다. 그런데 해가 지자 마을이 어두워졌습니다.
- **주인공**: 학생(또는 학생 모둠) = "탐험대". 이야기 속 인물이 학생이 정한 이름(혼자 하기) 또는 모둠 이름(모둠으로 하기)으로 부릅니다.
- **안내 인물**: 마을의 불빛을 지키는 빛 요정 "반디"(꼬리가 빛나는 반딧불이). 탐험대에게 도움을 요청하고 각 단계를 안내합니다.
- **마을 사람**: 여러 동물(병아리, 곰 등). 장소마다 문제 상황을 말풍선으로 알려 줍니다.
- **문제**: 가로등이 꺼져 있고, 광장의 안내 종이 울리지 않고, 언덕의 풍차가 멈춰 있어 축제를 열 수 없습니다.
- **해결**: 미션 세 개를 해결할 때마다 그 장소가 되살아나고 마을이 점점 밝아집니다. 세 곳을 모두 되살리면 마을 전체에 불이 켜지고 불꽃놀이와 함께 축제가 시작됩니다.
- 교과서 3차시 이야기와는 잇지 않은, 이 게임만의 이야기입니다.

## 3. 전체 흐름

```
오프닝 영상 → S1 입장 → S2 도입(이야기 5장면) → S3 마을 지도 ⇄ S4 미션(3개) → S5 마무리(7단계) → 축제 엔딩
```

| 단계 | 화면 | 하는 일 | POE |
|---|---|---|---|
| 0 | 오프닝 | 밤의 반짝마을이 나타나는 짧은 연출. "시작하기" 또는 "건너뛰기" | - |
| 1 | S1 입장 | 혼자 하기 / 모둠으로 하기 선택, 이름 입력, 안전 약속 체크 | - |
| 2 | S2 도입 | 반디의 이야기, 회로 조건 떠올리기, 전지 제품 이야기와 예상 | 사전 지식 확인 |
| 3 | S3 지도 | 마을을 돌아다니며 미션 장소 찾기 | - |
| 4 | S4 미션 ×3 | 예상 → 만들기 → 비교·이유 → 확인 | P → O → E |
| 5 | S5 마무리 | 결과 모으기, 생각 나누기, 설명하기(용어 "직렬연결" 처음 등장), 확인, 오개념 점검, 스스로 평가 | 정리·평가 |

## 4. 화면별 상세 기능

### 4-1. 오프닝
- 밤하늘, 반딧불, 어두운 마을이 차례로 나타나는 애니메이션과 제목 "불빛 탐험대 / 꺼진 마을을 밝혀라".
- 처음 접속하거나 "처음부터 다시 하기"를 했을 때만 나옵니다.

### 4-2. S1 입장
- **혼자 하기**: "내 이름을 써 주세요." 칸에 이름을 씁니다(예: 민수). 반디가 이 이름으로 부릅니다.
- **모둠으로 하기**: 선생님이 미리 만든 모둠 목록(1모둠, 2모둠 …)에서 우리 모둠을 고르고, "내 이름을 써 주세요."에 이름을 씁니다.
- **안전 약속 3가지**를 모두 체크해야 시작할 수 있습니다.
  1. 전기 부품을 만질 때는 절연 장갑을 끼고, 젖은 손으로 만지지 않아요.
  2. 전구의 유리 부분은 깨지기 쉬우니 조심해서 다뤄요.
  3. 전선의 집게에 손이 끼지 않게, 날개 달린 전동기에 손을 다치지 않게 조심해요.

### 4-3. S2 도입 (이야기 5장면)
화면 양옆의 꺾쇠(‹ ›)나 키보드 ←/→로 넘깁니다. 장면마다 움직이는 그림이 있습니다.

| 장면 | 내용 |
|---|---|
| 1 | 해설: 반짝마을, 불빛 축제 날인데 마을이 어둡다 |
| 2 | 반디 등장: "○○, 와 줘서 고마워요! … 가로등은 꺼져 있고, 광장의 안내 종은 울리지 않고, 언덕의 풍차는 멈춰 있어요." |
| 3 | **회로 조건 떠올리기**(복습): "전구에 불이 켜지는 전기 회로는 전지의 양 끝과 전구, 전선이 ( ) 연결되어 있어요." → 끊기지 않게 / 끊기게. 고르면 빈칸이 채워지고 맞음·틀림 안내가 나옵니다 |
| 4 | **전지 제품 이야기**(손 선풍기·손전등·리모컨): ① 제품마다 전지 개수가 다른 까닭(필요한 전기의 양이 달라서 / 많을수록 무조건 좋아서 / 잘 모르겠어요) ② 전지 1개·2개 손 선풍기 중 바람이 더 센 것 예상 |
| 5 | 반디의 부탁: "전지의 개수를 달리해서 축제 전에 반짝마을을 다시 밝혀 줄래요?" → "마을로 출발" |

### 4-4. S3 반짝마을 지도 (돌아다니기)
- 탐험대 캐릭터(머리 전등 헬멧을 쓴 강아지)를 **직접 움직여** 마을을 돌아다닙니다.
  - 조작: 방향키/WASD, 가고 싶은 곳 누르기(마우스·터치), 화면 오른쪽 아래 조이스틱
- **보기 두 가지**: "탐험"(캐릭터를 따라가며 크게, 기본) / "지도"(마을 전체). 오른쪽 위 버튼으로 바꿉니다.
- **나침반 화살표**가 다음 미션 장소를 가리키고, 장소 위에 반짝이는 화살표가 있습니다.
- 처음 도착하면 반디의 인사 후 **움직이는 방법 튜토리얼**(연습 모드: 돌아다니기만 하고 미션은 열리지 않음)이 나옵니다. 왼쪽 아래 "?"로 다시 볼 수 있습니다.
- **미션 장소 3곳**: 가로등 거리(미션 1) → 광장의 안내 종(미션 2) → 언덕의 풍차(미션 3). 앞 미션을 해결해야 다음 장소가 열립니다(잠긴 곳은 자물쇠 표시).
- 장소에 도착하면 **상황 장면**(움직이는 그림 + 마을 동물의 말)과 "문제 상황 / 우리가 할 일"이 뜨고 "미션 시작!"을 누릅니다.
- 미션을 마치고 돌아오면 그 장소가 **되살아나는 장면**(서서히 밝아짐)과 반디의 다음 안내가 나옵니다. 위쪽 제목: "[이름] 미션 n/3 완료"와 별 세 개.
- 완료한 장소는 "결과 확인하기"(보기만) 또는 "다시 하기"(처음부터 새로)를 고를 수 있습니다.
- 세 곳을 모두 되살리면 "마무리로 가기".

### 4-5. S4 미션 화면 (공통 틀)
화면 구성: 위쪽 줄(미션 제목, 단계 칩 "예상·만들기·비교·이유·확인", 나가기·지도·어둡게 보기·소리 버튼) / 왼쪽 A 회로판(전지 1개) / 가운데 B 회로판(전지 2개) / 오른쪽 학습지 / 아래 안전 문구.

들어갈 때마다 먼저 **반디의 미션 이야기**(3~4장면, 언제든 ✕나 건너뛰기로 닫기 가능)가 나옵니다.

| 단계 | 하는 일 | 규칙 |
|---|---|---|
| ① 예상 | 선택지 3개 중 하나를 고르고 "이걸로 정했어요" | 정한 예상은 바꿀 수 없음. 정답을 미리 알려 주지 않음 |
| ② 만들기 | 회로판에서 직접 A·B 회로를 만들고 스위치를 닫아 비교 | 오른쪽 "탐험 과제" 3칸이 판정 결과로 **자동 체크**됨. 3칸이 모두 체크되어야 "비교하러 가기" |
| ③ 비교·이유 | 문장의 빈칸 ○표 고르기(예: 전구의 밝기가 더 ( 어둡다 / 밝다 )) + 모둠 이유 쓰기 | 이유를 **10글자 이상** 써야 "확인하기". 확인하기를 누르면 그 자리에서 채점(○표 맞음/틀림, 정답에 빨간 테두리)과 **모범 답안**이 나오고, 이후 고칠 수 없음 |
| ④ 확인 | 성공 축하(반디) → 내 예상 / 실제 결과, 예상이 맞았는지, 한 줄 정리, 장소 되살아남 | "지도로 돌아가기"를 누르면 미션 완료로 기록 |

**POE 원칙**: 확인(④) 전에는 정답이나 원리를 보여 주지 않습니다. 미션 화면에서는 "직렬"이라는 용어도 쓰지 않습니다. 용어는 S5 설명하기에서 처음 나옵니다.

**할 곳만 밝히기**: ①·③·④에서는 화면을 어둡게 덮고 지금 할 곳(학습지)만 밝게 보여 줍니다. ② 만들기에서는 탐험 과제를 같이 봐야 해서 덮지 않습니다.

**어둡게 보기**(미션 1만): 회로판 배경을 어둡게 바꿔 전구 밝기 차이를 더 잘 보이게 합니다.

**도움말·심화**: 탐험 과제 아래 "도움말" 토글(예: "주변이 어두우면 밝기를 더 잘 볼 수 있어요."), 미션 3 확인 단계의 "더 알아보기 (심화)"(전동기 방향이 전기의 방향에 따라 바뀌는 원리).

### 4-6. 미션 3개 상세

| | 미션 1. 가로등 밝히기 | 미션 2. 광장의 안내 종 울리기 | 미션 3. 언덕의 풍차 돌리기 |
|---|---|---|---|
| 부품 | 전구 | 버저(안내 종) | 날개 달린 전동기(풍차) |
| 비교하는 것 | 밝기 | 소리의 세기 | 도는 빠르기 |
| 예상 정답 | (가) 전지 2개 회로의 전구가 더 밝을 것 같아요 | (가) 전지 2개 회로의 소리가 더 클 것 같아요 | (가) 전지 2개 회로의 날개가 더 빠르게 돌 것 같아요 |
| ○표 정답 | 밝다 | 크다 | 빠르게 |
| 관찰 문구 | A: "전구가 희미하게 켜졌어요." / B: "전구가 훨씬 환하게 켜졌어요!" | A: "안내 종이 작게 울려요." / B: "안내 종이 더 크게 울려요!" | A: "풍차가 느리게 돌아요." / B: "풍차가 빠르게 돌아요!" |
| 특징 | 어둡게 보기, 도전(선택) | 버저는 빨간 선을 +쪽에 이어야 울림. 소리 크기가 실제로 다름 | 전선을 바꿔 이으면 도는 방향이 바뀜(심화) |
| 이유 쓰기 안내 | "왜 그랬을까요? 모둠이 함께 이유를 써 보세요." | "가로등 미션과 비슷한 점이 있었나요?" | "앞의 두 미션에서 본 것과 비교해서" |

**모범 답안(미션 1 예)**: "전지 2개를 서로 다른 극끼리 한 줄로 연결하면 전지 1개일 때보다 전구에 전기 에너지가 더 많이 공급되기 때문에 전구가 더 밝아져요."

**탐험 과제(체크리스트, 미션 1 예)**
1. A 회로: 전지 1개와 전구, 스위치를 집게 달린 전선으로 연결해 보세요.
2. B 회로: 전지 2개를 서로 다른 극끼리 한 줄로 이은 뒤 전구, 스위치를 연결해 보세요.
3. 두 회로의 스위치를 모두 닫고 전구의 밝기를 비교해 보세요.

### 4-7. 회로 시뮬레이터

**조작**
- 단자(동그란 금속 부분)를 누른 채 다른 단자까지 끌면 집게 달린 전선이 생깁니다. 단자 두 개를 차례로 눌러도 됩니다.
- 전선을 누르면 지워집니다.
- 스위치를 누르면 열림/닫힘이 바뀝니다(처음에는 열림).
- 부품 위치는 고정되어 있고, 학생은 연결만 합니다.

**결과 표현**
- 전구: 밝기 2단계(전지 1개 희미함 / 전지 2개 환함). 전지 2개 쪽이 더 노랗고 빛번짐이 큼.
- 버저: 종소리 "딩~". 전지 2개 쪽이 확연히 크게 울림. A·B가 번갈아 울려 비교하기 쉬움.
- 전동기: 날개 회전 빠르기 차이, 도는 방향 표시.
- 전구가 켜질 때 효과음.

**판정 규칙**(순수 함수 `judge`, 단위 테스트 있음)
- 단자를 노드, 부품을 변으로 보는 그래프로 회로를 분석합니다. 부품을 지나는 닫힌 고리를 찾고, 고리 위 전지의 방향 합으로 작동 레벨(0·1·2)과 전기의 방향을 정합니다.
- 판정 결과(이유)마다 힌트 문구가 1:1로 대응합니다.

| 판정 이유 | 상황 | 힌트 문구 |
|---|---|---|
| NO_WIRES | 전선이 하나도 없음 | 부품의 끝(동그란 금속 단자)을 집게 달린 전선으로 이어 보세요. |
| BROKEN | 고리가 끊김 | 전지의 양 끝(+, −)과 부품이 끊기지 않게 이어져야 해요. 끊어진 곳이 없는지 살펴보세요. |
| SWITCH_OPEN | 연결은 맞고 스위치만 열림 | 스위치가 열려 있어요. 눌러서 닫아 보세요. |
| SWITCH_MISSING | 스위치를 빼고 고리를 만듦 | 스위치도 고리 안에 함께 이어 보세요. |
| SAME_POLE | 전지 2개를 같은 극끼리 이음 | 전지 2개는 서로 다른 극끼리 이어야 해요. 한 전지의 + 와 다른 전지의 − 를 이어 보세요. |
| BUZZER_REVERSED | 버저 극을 반대로 이음 | 버저가 울리지 않으면 … 빨간 선은 전지의 + 쪽에 이어요. |
| SHORT_CIRCUIT | 부품을 거치지 않고 전지 양 끝이 바로 이어짐(합선) | 부품을 거치지 않고 전지의 양 끝이 바로 이어졌어요. … |

**힌트 시점**: 연결을 바꾸지 않고 **5초**가 지나면 회로판 아래 말풍선으로 힌트가 나옵니다. 힌트를 본 횟수와 전선을 잇거나 지운 횟수(시도)는 교사용 기록에 남습니다.

### 4-8. 회로 만들기 튜토리얼
- 미션 1의 ② 만들기에 처음 들어갈 때 자동으로 나옵니다. 기기마다 한 번만 자동으로 나오고, 이후에는 위쪽 "연결 방법 다시 보기"로 엽니다.
- 4단계: **전선 잇기 → 전선 지우기 → 스위치 누르기 → 이제 스스로!**
- 연습할 회로판만 밝게 드러나고, 반짝이는 고리와 시범 커서(큰 화살표)가 할 곳을 가리킵니다. 카드는 회로판 옆에 뜹니다.
- 학생이 실제로 해 보면 저절로 다음 단계로 넘어갑니다(**내가 한 조작으로만** 넘어감).

### 4-9. 도전! (선택 보충, 미션 1)
- ④ 확인 단계의 "도전! 더 해 보기 (선택)". B 회로의 전지 두 개를 **같은 극끼리** 이어 보는 활동입니다.
- 3단계 안내가 있고, 힌트를 토글로 하나씩 열어 볼 수 있습니다(정답을 바로 보여 주지 않음).
- 마치면: "전지를 늘리기만 해서는 안 되고, 서로 다른 극끼리 한 줄로 이어야 해요."
- 도전 중의 조작은 힌트·시도 횟수에 넣지 않습니다.

### 4-10. S5 마무리 (7단계, 모둠으로 할 때도 **각자** 진행)

| 단계 | 내용 | 규칙 |
|---|---|---|
| 1. 결과 모아 보기 | 미션별 "내 예상 / 실제 결과" 표 (자동 채움) | - |
| 2. 함께 생각을 나누기 | 문장 틀의 빈칸 3개에 직접 쓰기: "…전구는 ( ), 버저는 ( ), 날개 달린 전동기는 ( )." | 세 칸을 모두 써야 다음 |
| 3. 설명하기 | 반디: "그동안 알아낸 것을 정리해 볼까요?" 질문 3개(전구 밝기 / 버저 소리 / 전동기 빠르기: 더 ~했어요·덜 ~했어요·같았어요). 다 답하면 정리 문장이 나옴. **"직렬연결" 용어가 처음 등장** | 세 질문 모두 답해야 다음 |
| 4. 확인해요 | "…전지 2개를 직렬연결한 전기 회로에서 전구의 밝기가 더 ( 밝습니다 / 어둡습니다 )." | 한 번만 고름. 바로 "정답이에요."(초록) 또는 "정답은 '밝습니다'예요."(빨강)와 해설. 맞든 틀리든 다음 가능 |
| 5. 오개념 점검 | O/X 3문항 | 한 번만 고름. 바로 정답·해설 |
| 6. 스스로 평가 | "전지 개수에 따른 전구의 밝기를 비교하고, 전지 개수에 따른 전기 회로의 특징을 설명할 수 있나요?" 잘할 수 있어요 / 조금 도움이 필요해요 / 더 연습이 필요해요 | 점수는 보여 주지 않음 |
| 7. 마치기 | 화면 전체가 환하게 되살아난 마을과 불꽃놀이 엔딩 "마을이 환하게 되살아났어요!" → "탐험 마치기" → "수고했어요, 탐험대!" | - |

**설명하기 정리 문장(4개)**
1. 전지 여러 개를 서로 다른 극끼리 한 줄로 연결하는 방법을 전지의 직렬연결이라고 해요.
2. 전지 2개를 직렬연결하면 전지 1개를 연결했을 때보다 전구는 더 밝고, 버저의 소리는 더 크고, 날개 달린 전동기는 더 빠르게 돌아요.
3. 전지 2개를 직렬연결하면 전지 1개를 연결할 때보다 전기 에너지가 더 많이 공급돼요.
4. 직렬연결한 전지의 개수를 늘릴수록 전구를 더 밝게 할 수 있고, 버저로 더 큰 소리를 내거나 전동기를 더 빠르게 돌릴 수 있어요.

**오개념 점검 문항**

| 번호 | 문항 | 정답 | 해설 |
|---|---|---|---|
| ① | 전선이 연결되어 있기만 하면 전구에 불이 켜져요. | X | 스위치가 열리거나 전선이 끊기면 전기가 흐르지 않아 불이 켜지지 않아요. |
| ② | 전지의 개수가 늘어나면 전구는 무조건 더 밝아져요. | X | 직렬연결에서 밝아지는 것을 살펴봤어요. 연결하는 방법이 맞지 않으면 달라질 수 있어요. |
| ③ | 전지 2개를 직렬연결한 회로의 버저는 전지 1개일 때보다 소리가 더 커요. | O | 전지 2개를 직렬연결하면 버저 소리가 더 커져요. |

## 5. 두 가지 모드: 혼자 하기 / 모둠으로 하기

| | 혼자 하기 | 모둠으로 하기 |
|---|---|---|
| 들어가기 | 내 이름 입력 | 선생님이 만든 모둠 선택 + 내 이름 |
| 기기 | 1대 | 모둠원 각자 1대씩 (모두 같은 게임 주소로 접속하고 인터넷이 되면 됨) |
| 도입·미션 | 혼자 진행 | 같은 화면을 **실시간으로 함께** 조작 |
| 고르는 문제 | 고르면 바로 정해짐 | **모두 동의**: 모둠원 모두 같은 답을 골라야 정해짐 |
| 회로판 | 혼자 조작 | 누구나 두 회로판을 함께 조작, 친구 커서와 조작이 보임 |
| 튜토리얼 | 진짜 회로판에서 | 각자 **연습용 회로판**에서, 모두 끝나야 함께 시작 |
| 마무리 | 혼자 | **각자** 자기 속도로, 기록도 학생별 |

### 5-1. 모둠 실시간 공동작업 기능 (모둠으로 하기)

- **위쪽 모둠 줄**: 모둠 이름과 지금 들어와 있는 모둠원 이름(각자 고유 색 점, 나는 "(나)"). 마무리 화면에서는 보이지 않습니다.
- **같은 화면 함께 쓰기**: 한 명이 조작하면 같은 모둠 모든 기기 화면에 같은 결과가 반영됩니다(도입 장면 넘기기, 미션 단계, 회로판, 학습지).
- **친구 커서**: 미션 화면 어디서든 친구의 커서가 이름표와 함께 보입니다. 화면 크기가 달라도 같은 요소·같은 지점을 가리키도록 위치를 맞춥니다.
- **친구가 끄는 전선**: 친구가 전선을 끌고 있으면 친구 색 점선으로 보입니다.
- **회로판 조작 알림**: 친구가 회로판을 조작하면 그 회로판 위에 "지아: 전선을 이었어요"가 3초 동안 뜹니다.
- **지도에서 친구 캐릭터**: 친구 캐릭터가 친구 색 발밑 고리와 이름표를 달고 실시간으로 움직입니다. 내 캐릭터 위에도 이름표가 있습니다.
- **모이기**: 미션 장소에서 "미션 시작!"은 **지금 들어와 있는 모둠원이 모두 그 장소에 와야** 눌립니다. 누가 도착했는지("✓ 민지 / 지아 · 오는 중")와 "(1/2명)"이 보입니다.
- **모두 부르기 / 함께 가기**: 도착한 사람이 "모두 부르기"를 누르면 친구 화면에 "민지 친구가 가로등에서 기다려요 [함께 가기]"가 뜨고, 누르면 그 장소로 바로 이동합니다.
- **미션은 함께 들어가고 함께 나옴**: 한 명이 "미션 시작"을 누르면 모두 함께 들어가고, "지도"를 누르면 모두 함께 나옵니다.
- **모두 동의**: 도입의 세 질문, 미션의 예상과 ○표 비교에서 각자 고르면 선택지 옆에 고른 친구의 색 동그라미(이름 첫 글자)가 붙습니다. 모두 같은 답을 골라야 정해지고, 나중에 누가 답을 바꾸면 다시 같아질 때까지 다음으로 넘어갈 수 없습니다. 도입에서는 "모둠원 모두 같은 답을 골라야 정할 수 있어요 (1/2명)" 안내가 함께 보입니다.
- **쓰는 중 잠금**: 서술형 칸(미션 이유)을 누가 쓰고 있으면 다른 친구 화면에 "민지 쓰는 중…"이 뜨고 그 칸이 잠깁니다. 쓰는 글자는 실시간으로 모두에게 보입니다.
- **채점·결과 함께 보기**: ③에서 한 명이 "확인하기"를 누르면 모두에게 채점이 함께 뜨고, ④ 축하 창의 "결과 보기"도 한 명이 누르면 모두 함께 넘어갑니다.
- **튜토리얼 각자 연습**: 처음 튜토리얼은 각자 "연습용 회로판 (나만 보여요)"에서 합니다. 먼저 끝낸 사람은 화면이 뿌옇게 덮이고 "친구들이 회로 연결 방법을 익히고 있어요 (1/2명 끝냈어요)"가 뜹니다. 모두 끝나면 함께 모둠 회로판에서 만듭니다.
- **이야기 창은 각자**: 미션을 마친 뒤 지도에 뜨는 반디 이야기("알겠어요")는 각자 읽고 닫습니다.
- **마무리는 각자**: "마무리로 가기"를 각자 누르면 누른 사람만 마무리로 넘어가고, 7단계를 각자 진행합니다. 친구의 답은 보이지 않습니다.
- **연결 안정성**: 모둠의 기기 중 한 대가 15초마다 전체 상태를 보내 놓친 조작을 맞춥니다. 새로고침해도 같은 모둠으로 다시 들어갑니다. 늦게 들어온 친구는 서버에 저장된 상태와 친구 기기에서 현재 화면을 받습니다.

## 6. 교사용 화면 (`/teacher`)

- **로그인**: 반디 그림과 "불빛 탐험대 / 선생님용 화면", 비밀번호 칸. 비밀번호는 서버 설정값(환경 변수)으로 정합니다.
- 왼쪽 **사이드바 메뉴**로 한 화면씩 봅니다. 10초마다 자동으로 새로 불러옵니다(최근 12시간 안의 기록).

| 메뉴 | 기능 |
|---|---|
| 한눈에 보기 | 숫자 카드(모둠 수, 완료한 미션, 마무리 기록 인원, 탐험을 마친 사람) + 막대 그래프 두 묶음. **미션 · 모둠**: 미션별 완료한 모둠, 예상이 맞은 모둠, ○표 비교를 맞힌 모둠, 힌트를 많이 본 모둠. **마무리 · 개인**: 설명하기를 맞힌 사람(전구 밝기·버저 소리·전동기 빠르기), 스스로 평가 분포, 오개념 점검을 맞힌 사람(문항 내용과 정답 표시). 그래프 제목 앞에 [미션]/[마무리] 표시가 있고, 막대 옆에 "3/5 (60%)"처럼 숫자 표시 |
| 모둠 진행 | 모둠별 지금 위치(예: 미션 · 가로등 ② 만들기), 되살린 곳 수, 미션별 힌트/시도, 쓴 글 수. 페이지 나누기 |
| 기록 | 탭 2개. **모둠 기록(도입·미션)**: 모둠마다 도입 답 3개, 미션 3개 카드(예상·정상 연결 A/B·○표 비교에 ✓맞음/✗틀림 표시, 힌트/시도, 도전 여부, 모둠이 쓴 이유). **개인 마무리 기록**: 학생 한 명이 한 줄(진행 단계, 생각 나누기 빈칸, 설명하기 1·2·3, 확인해요, 오개념 1·2·3, 스스로 평가). 둘 다 페이지 나누기 |
| 모둠 관리 | 모둠 수를 정해 "모둠 만들기"(1모둠, 2모둠 … 이름 순으로 정렬), 모둠 지우기(앱 모양 확인 창) |
| 평가 기준 | 지도서 평가 요소 3개(과정·기능 / 지식·이해 / 가치·태도)와 상·중·하 기준, 보는 내용, 근거 자료(참고용) |

- 점수나 상·중·하를 자동으로 매기지 않습니다. 근거 자료만 보여 주고 판단은 교사가 합니다.
- 힌트를 3번 이상 본 곳은 빨간 굵은 숫자로 표시해 도움이 필요한 모둠을 찾기 쉽게 합니다.

## 7. 기록되는 데이터 (학습 기록)

모둠 하나의 기록 전체를 한 덩어리(JSON)로 저장합니다. 혼자 하기는 한 사람이 한 "모둠"입니다.

| 영역 | 기록 내용 |
|---|---|
| 기본 | 모둠 id, 모둠 이름, 지금 화면·미션·단계 |
| 도입 | 회로 조건 떠올리기(처음 고른 답의 맞음/틀림), 전지 개수가 다른 까닭, 손 선풍기 예상 |
| 미션별 | 상태(잠김/진행/완료), 예상, A·B 정상 연결 여부, ○표 비교, 모둠 이유(글), 힌트 본 횟수, 시도(전선 잇기·지우기) 횟수, 완료 시각, 마지막 회로판, 도전 여부, 확인하기(채점) 여부 |
| 마무리 | 혼자 하기: 모둠 기록에. 모둠으로 하기: **학생별**로 생각 나누기 빈칸 3개(와 완성 문장), 설명하기 3답, 확인해요(처음 고른 답), 오개념 3문항 맞음/틀림(처음 고른 답), 스스로 평가, 진행 단계, 마침 여부 |

저장 위치: 브라우저(localStorage)에 항상 저장하고, 서버 저장이 켜져 있으면 2초에 한 번 서버(Supabase DB)에도 저장합니다. 개인정보는 학생이 입력한 이름(별명 가능) 외에는 받지 않습니다.

## 8. 소리와 화면 연출

- **배경 음악**: 오르골 느낌의 잔잔한 반복 음악(음원 파일 없이 브라우저에서 직접 합성). 탭을 여러 개 열어도 한 곳에서만 연주합니다.
- **효과음**: 버튼 누를 때 작은 "톡", 창이 열릴 때, 전구가 켜질 때, 미션 성공 때, 버저 종소리.
- **소리 버튼**: 오른쪽 위에서 언제든 끄고 켤 수 있고, 기기에 기억합니다. 이야기 창이 떠 있어도 누를 수 있습니다.
- **나가기**: 도입·지도·미션·마무리 어디서든 "나가기"(확인 창 "처음 화면으로 돌아갈까요?")로 처음 화면으로 돌아갈 수 있습니다. 이 기기의 기록만 지우고 선생님 화면의 기록은 남습니다.
- **모든 팝업에 ✕**: 이야기·튜토리얼·상황 장면 등 떠 있는 창은 언제든 닫을 수 있습니다.
- **그림체**: 모든 그림(마을, 캐릭터, 부품, 아이콘)을 이미지 파일 없이 SVG 도형으로 직접 그려 통일했습니다. 이모지를 쓰지 않습니다.
- **안전 문구**: 미션 화면 아래에 항상 안전 문구가 보입니다.

## 9. 기술 구성

| 영역 | 사용 기술 |
|---|---|
| 프론트엔드 | Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS 4 |
| 그림·애니메이션 | SVG + CSS 애니메이션 (이미지 파일 없음) |
| 소리 | Web Audio API (음악·효과음 실시간 합성) |
| 실시간 동기화 | Supabase Realtime (broadcast + presence) |
| 서버 저장 | Supabase PostgreSQL (`group_sessions` 표 하나), Next.js Route Handler가 서버 전용 키로 읽고 씀 |
| 테스트 | Vitest 단위 테스트 (회로 판정, 단계 규칙, 동기화 규칙, 모두 동의·쓰는 중 잠금, 교사 통계 등 84개) |

**핵심 설계**
- **상태 변경은 reducer 하나로**: 모든 게임 상태 변화는 한 곳(결정적 reducer)에서만 일어납니다. 시각·id는 action에 담아 보내서, 같은 action을 모둠의 모든 기기에 보내면 화면이 똑같아집니다.
- **두 층 동기화**: ① 공유 기록(회로·답·단계)은 action을 모든 기기에 보내 저장까지 하고, ② 실시간 존재감(커서·캐릭터 위치·쓰는 중·고른 답 표시)은 저장하지 않는 가벼운 메시지로 초당 약 15번 보냅니다.
- **판정은 순수 함수**: 회로 판정은 화면과 분리된 함수라서 테스트로 검증합니다.
- **문구는 한 파일에**: 학생 화면 문구를 모두 `src/data/strings.ts`에 모아, 교사가 문구만 고치기 쉽습니다.
- **보안**: 서버 전용 키는 브라우저에 보내지 않고, DB는 브라우저에서 직접 접근할 수 없게 막았습니다(RLS). 교사 API는 비밀번호로 보호합니다.
- **3단계 구성**: 환경 설정 없이도 1단계(브라우저 저장만)로 동작하고, 설정을 넣으면 2단계(서버 저장·교사 화면), 3단계(모둠 실시간)가 켜집니다.

## 10. 교육적 설계 의도 (보고서용)

- **POE 순서 지키기**: 예상을 먼저 정하고 바꿀 수 없게 해 학생의 처음 생각을 기록합니다. 확인 전에는 정답·원리를 보여 주지 않고, 용어("직렬연결")는 관찰을 모두 마친 뒤 마무리에서 처음 제시합니다.
- **직접 만들며 관찰**: 부품 위치는 고정하고 연결만 맡겨, 조작의 어려움보다 "전지 개수에 따른 차이" 관찰에 집중하게 했습니다. 두 회로를 나란히 놓아 바로 비교할 수 있습니다.
- **같은 원리, 세 가지 현상**: 전구(빛)·버저(소리)·전동기(움직임)에서 같은 결과를 반복 확인해 일반화하도록 미션을 배치했습니다. 이유 쓰기 질문도 "앞 미션과 비슷한 점"을 묻도록 점점 바뀝니다.
- **막혔을 때 단계적 도움**: 5초 멈추면 상황에 맞는 힌트, 도움말 토글, 도전 활동의 단계별 힌트로 스스로 해결하게 돕습니다. 힌트 횟수는 교사에게 도움이 필요한 모둠을 알려 주는 근거가 됩니다.
- **오개념 다루기**: "전선만 연결되면 켜진다", "전지가 많으면 무조건 밝다"를 O/X로 점검하고, 도전 활동(같은 극끼리 잇기)으로 "연결 방법"의 중요성을 직접 확인하게 했습니다.
- **협력과 개인 책임의 균형**: 탐구(도입·미션)는 모둠이 함께 하되 "모두 동의"로 모둠원 모두가 의견을 내게 하고, 정리·평가(마무리)는 각자 하게 해 개인별 이해도를 확인합니다.
- **게임 요소**: 이야기, 돌아다니는 마을, 되살아나는 장소, 축제 엔딩으로 동기를 높이고, 안전 약속을 시작과 미션 화면에 넣어 실제 실험 안전 교육과 연결했습니다.
- **교사 지원**: 자동 채점·점수 대신 근거 자료와 통계를 보여 주어 교사가 지도서 평가 기준으로 판단하도록 했습니다.

## 11. 한계와 남은 일

- 교사용 평가 기준(상·중·하) 문장은 임시 문장이라 지도서 문장으로 바꿔야 합니다.
- 태블릿 실기기에서 글자·버튼 크기, 움직임의 부드러움, 마무리 7분 안에 끝나는지 확인이 필요합니다.
- 학생 화면의 "나가기"는 그 기기의 기록만 지웁니다. 모둠으로 할 때는 진행 기록이 서버에 남아 있어서, 같은 모둠을 다시 고르면 하던 곳부터 이어서 합니다. 모둠을 처음부터 다시 하려면 교사가 교사용 화면의 모둠 관리에서 그 모둠을 지우고 다시 만듭니다. 학생 화면에는 모둠 전체 기록을 지우는 버튼을 일부러 넣지 않았습니다(수업 중 실수로 지우는 일을 막기 위해).
- 같은 와이파이의 다른 기기에서 http 주소로 접속할 때를 위해 보안 연결(https)이 아니어도 동작하도록 만들었지만, 실제 수업 배포는 https 주소를 권장합니다.
